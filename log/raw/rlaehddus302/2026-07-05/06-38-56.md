> "**You must enable AWS WAF if you want to view security metrics** in the CloudFront Security dashboard. **If you don't enable AWS WAF, you can only use the Security dashboard to enable AWS WAF or configure CloudFront geographic restrictions.**"

이 문장을 뒤집어 보면: **AWS WAF를 이미 활성화한 상태에서는, Security 대시보드 화면에 "지역 제한을 설정하는" 진입점이 안 뜨고 WAF 통계 화면(방금 캡처하신 화면)으로 바로 넘어갑니다.** 캡처를 보면 "코어 보호 Enabled"라고 되어 있죠 — 즉 이미 WAF가 켜져 있는 상태라서, 대시보드가 지역 제한 설정 링크 대신 WAF 통계/봇 카테고리 화면을 우선 보여주는 것으로 보입니다. 이게 지금 안 보이는 진짜 원인일 가능성이 큽니다.

이 상태에서 지역 제한을 걸려면 두 가지 경로가 있습니다:

1. **CloudFront 자체 지역 제한(무료)**: 이 대시보드가 아니라, 배포 상세 페이지에서 "지정된 시간 범위의 보안 추세" 아래 있는 **"요청" 차트에서 국가별 바(bar)에 마우스를 올려서 직접 차단(Block)**하는 방식으로 우회 설정하게 만들어 놨습니다 (문서에 있는 "hover over a country bar in the security dashboard and block the country" 방식). 즉 UI가 "지역 제한"이라는 별도 메뉴 대신 이 차트 인터랙션으로 흡수해버린 것으로 보입니다.
2. **AWS WAF 지역 매치 규칙**: "Manage protections" 버튼을 눌러서 WAF 규칙에 국가 조건을 직접 추가하는 방식 — WAF가 이미 켜져 있으니 이 경로가 지금 계정 상태와 더 맞습니다.
