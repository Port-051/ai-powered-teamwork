맥에서 복사/붙여넣기는 `Command(⌘)` 키를 써요 (윈도우의 Ctrl 자리).

- **복사**: 텍스트 선택한 다음 `Command(⌘) + C`
- **붙여넣기**: `Command(⌘) + V`

**터미널에서 제가 드린 명령어 복붙하는 법**
1. 제 답변에서 코드 부분(예: `/bin/bash -c "$(curl...`)을 마우스로 드래그해서 선택 (또는 트랙패드로 텍스트 위에서 손가락으로 쓸어서 선택)
2. `Command + C`로 복사
3. 터미널 창 클릭해서 커서 갖다놓기
4. `Command + V`로 붙여넣기
5. `Enter` 눌러서 실행

윈도우처럼 `Ctrl+C` / `Ctrl+V` 누르면 터미널에서는 다른 기능(예: `Ctrl+C`는 "실행 중인 명령어 강제 중단")으로 동작하니까 헷갈리지 않게 주의하세요 — 무조건 `Command` 키예요.
