## 1) 워크스페이스 생성 — 맞아요, 원래 이래요

**네, 정상이에요.** 슬랙은 구조상 "워크스페이스"가 없으면 계정 자체가 존재할 수 없어요. 카카오톡처럼 개인 계정 하나로 여기저기 들어가는 게 아니라, **워크스페이스 = 회사/팀 하나의 전용 공간**이라는 게 슬랙의 기본 단위예요. 그래서 무료든 유료든, 혼자 쓰든 팀으로 쓰든 가입 시 무조건 워크스페이스를 만들거나 기존 것에 초대받아 들어가야 해요. 특이한 거 아니고 슬랙 자체의 정상적인 동작입니다.

## 2) 뭘 연습해보면 좋을까 — 우리 프로젝트에 바로 도움되는 순서

우리 프로젝트에서 제일 중요한 게 결국 **"`@ai` 멘션 → 봇이 알아채고 → 답장"** 왕복이에요. 이걸 슬랙에서 미리 연습해두면 나중에 Mattermost로 옮길 때 개념이 거의 그대로 통해요. 추천 순서:

### ① 채널·멘션·스레드 감 잡기 (5분)
- 채널 아무거나 하나 골라서 `@팀원이름`으로 불러보기
- 아무 메시지에 "스레드로 답장" 눌러서 답글 달아보기 → 이게 나중에 "지식 단위의 출처(세션)"라는 개념과 연결돼요

### ② 진짜 추천: 슬랙 봇 하나 직접 만들어보기 (가장 실전 연습)
이게 **Phase 3-1(API 통합 실전)**과 완전히 같은 패턴이라, 지금 해보는 게 제일 남는 연습이에요.

1. **`https://api.slack.com/apps`** 접속 → "Create New App" → "From scratch"
2. 방금 만든 워크스페이스 선택 → 앱 이름 정하기 (예: `ai-bot-test`)
3. 왼쪽 메뉴 **"OAuth & Permissions"** → Bot Token Scopes에 `chat:write`, `app_mentions:read` 추가
4. 왼쪽 메뉴 **"Event Subscriptions"** 켜기 → `app_mention` 이벤트 구독 (누가 봇을 멘션하면 알림 받는 설정)
5. "Install to Workspace" → **봇 토큰(비밀번호 같은 열쇠)** 발급받음
6. 봇을 아무 채널에 초대(`/invite @ai-bot-test`) → `@ai-bot-test 안녕` 쳐보기

여기까지만 해도 "이벤트 구독 → 우리 코드가 감지 → API로 답장"이라는, **우리가 실제로 짤 어댑터의 핵심 뼈대**를 손으로 만져본 게 돼요.

### ③ (여유 되면) 봇이 실제로 답하게 코드 한 줄
Python으로 5분이면 됨:
```python
# slack_sdk 설치 후
from slack_sdk import WebClient
client = WebClient(token="발급받은 봇 토큰")
client.chat_postMessage(channel="채널ID", text="안녕하세요! 저는 봇입니다.")
```
이거 한 번 성공시키면 "REST API로 메시지 보내기"가 실제로 뭔지 체감이 확 와요.
