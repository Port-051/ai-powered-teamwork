## "토큰 격리"가 뭘 말하는가

프로파일의 `.env`에는 성격이 **다른 두 종류**의 값이 들어 있어요. 둘 다 `.env`에서 오지만 **쓰이는 목적·시점·코드가 완전히 달라요.**

**① 봇 토큰 (credential/token)** — 예: `MATTERMOST_TOKEN`
- 게이트웨이가 **"이 봇으로 로그인"** 할 때 쓰는 자격증명. 사람으로 치면 **봇 자신의 사원증/비밀번호**예요.
- default는 `@rlaehddus302bot` 토큰, sandbox는 `@testbot` 토큰. 각자 자기 토큰으로 로그인해야 "다른 봇"으로 붙어요.
- **"토큰 격리"** = 각 프로파일이 **자기 토큰으로 접속**하게 만드는 것. 이게 깨지면 sandbox가 default 토큰으로 붙어서 **둘 다 같은 봇**이 돼버려요 (이슈 #52446의 헤드라인).
- → **PR #57417이 고치는 게 이거.** (참고로 우리 테스트에선 이미 @testbot이 자기 토큰으로 잘 붙었어요.)

**② 허용 사용자 목록 (authorization)** — 예: `MATTERMOST_ALLOWED_USERS`
- 봇이 **"이 사람 말을 들어줄지 말지"** 판단할 때 쓰는 목록. 사람으로 치면 **문 앞의 초대 손님 명단**이에요.
- 봇이 로그인한 뒤, **메시지가 올 때마다** `_is_user_authorized`가 이 명단을 확인해요.
- → **PR #57417이 안 건드리는 게 이거.** 여전히 `os.getenv`로 전역(default) 명단만 봐요.

## 한 줄 비유

> **토큰** = 봇 자신의 **사원증**(누구로 로그인하나) → PR이 고침
> **ALLOWED_USERS** = 문 앞의 **손님 명단**(누굴 들여보내나) → 여전히 고장

그래서 PR #57417이 머지되면 **"봇들은 각자 제대로 로그인은 하는데(사원증 OK), 여전히 default의 손님 명단만 보고 문을 여닫는다(명단 고장)"** 상태가 돼요. 이 **명단 부분이 당신이 소유할 갭**이에요.

## 우리 PR에 적용되는 규칙 (체크리스트)

| 항목 | 규칙 | 우리 경우 |
|---|---|---|
| **브랜치명** | `fix/<설명>` | 예: `fix/multiplex-authz-allowlist-scope` |
| **커밋 메시지** | Conventional Commits `<type>(<scope>): ...` | `fix(gateway): ...` 또는 `fix(security): ...` |
| **테스트 필수** | `scripts/run_tests.sh` (CI와 동일) | `tests/gateway/test_multiplex_credential_isolation.py`를 본떠 authz 격리 테스트 추가 |
| **수동 테스트** | `hermes` 실행해 바꾼 경로 직접 실행 | 우리 2계정 재현이 그대로 수동 테스트 |
| **PR 설명** | What/Why + How to test(재현 단계) + 테스트한 OS + 관련 이슈 참조 | 로그 재현 첨부, #52446 참조 |
| **PR 하나 = 논리 하나** | 리팩터·기능 섞지 말 것 | authz 허용목록 수정만 |
| **보안 영향 명시** | 설명에 보안 영향 적기 | authorization 우회라 명시 |
| **의존성 핀** | 새 PyPI는 `<next_major` 상한 필수 | **우리는 새 의존성 없음 → 해당 없음** |

## 주의점 2가지

**① 보안 이슈 비공개 제보 규정** — CONTRIBUTING 끝에 "보안 취약점은 비공개로 제보하라"가 있어요. 원칙적으론 그런데, **이 버그는 이미 #52446(public, type/security)로 공개돼 있고 PR #57417도 공개로 고치는 중**이라, 그 공개 이슈에 이어서 공개 PR/코멘트로 가는 건 **현재 처리 방식과 일치**해요. (완전히 새로운 미공개 취약점이면 비공개로 갔겠지만, 이건 이미 공개된 갭이에요.)

**② 로컬 포크의 "carried commit" 함정** — 지금 `~/.hermes/hermes-agent`는 이미 **+1 carried commit이 얹힌 개조 포크**예요.
