## 1. `~/.hermes/.env` (실제 값을 적는 곳)

경로: `/home/rlaehddus302/.hermes/.env`

확인해보니 **`MATTERMOST_URL`, `MATTERMOST_TOKEN` 키는 이미 이 파일에 있습니다** (Hermes의 기존 Mattermost 어댑터 설정용으로 이미 채워져 있는 값). 그러니 우리 MCP 서버를 위해 따로 값을 또 적을 필요 없이, **`MATTERMOST_TEAM_ID` 한 줄만 추가**하면 됩니다:

```bash
# ~/.hermes/.env 맨 아래에 추가
MATTERMOST_TEAM_ID=여기_팀_ID
```

## 2. `~/.hermes/config.yaml` (Hermes에게 이 MCP 서버 존재를 알리는 곳)

경로: `/home/rlaehddus302/.hermes/config.yaml`

여긴 확인해보니 **`mcp_servers:` 항목이 아직 아예 없습니다.** 파일 맨 아래(또는 아무 최상위 위치)에 새로 추가해야 합니다:

```yaml
mcp_servers:
  mattermost_search:
    command: "python"
    args: ["/mnt/c/Users/kimye/OneDrive/바탕 화면/team-work/ai-powered-teamwork/experiments/hermes-mattermost/2026-07-11/dongyeon/mattermost-search-mcp/mattermost_search_mcp.py"]
    env:
      MATTERMOST_URL: "${MATTERMOST_URL}"
      MATTERMOST_TOKEN: "${MATTERMOST_TOKEN}"
      MATTERMOST_TEAM_ID: "${MATTERMOST_TEAM_ID}"
    tools:
      include:
        - search_mattermost
        - get_channel_recent_posts
        - get_thread
        - get_user_by_username
        - get_user_by_id
        - list_channels_for_team
```

`args`는 이 파일의 절대경로를 그대로 넣으면 됩니다.

정리하면: **값(토큰 등)은 `.env`, "이 도구를 써라"는 선언은 `config.yaml`** — 두 파일 다 이미 존재하니, `.env`엔 팀 ID 한 줄, `config.yaml`엔 `mcp_servers` 블록 전체를 추가하시면 됩니다.
