맥북 자체 자원(전체 CPU/메모리)을 보는 방법은 두 가지가 있어요.

**1) GUI로 보기 (제일 쉬움) — 활동 모니터**
- `Cmd + Space` → "활동 모니터" (Activity Monitor) 검색 후 실행
- 또는 Finder → 응용 프로그램 → 유틸리티 → 활동 모니터
- 탭 구성:
  - **CPU** 탭: 프로세스별 CPU 사용률. 상단 컬럼 클릭하면 정렬됨. `valkey-server`, `Python`(uvicorn/data.py) 이름으로 찾으면 됨
  - **메모리** 탭: 프로세스별 메모리 사용량 + 하단에 전체 메모리 압박(Memory Pressure) 그래프 — 초록/노랑/빨강으로 표시돼서 한눈에 여유 있는지 보임
  - **에너지** 탭: 어떤 프로세스가 배터리/전력을 많이 쓰는지

**2) 터미널로 보기**
```
top -o cpu
```
→ CPU 사용률 높은 순으로 실시간 정렬 (`q`로 종료). `-o mem`으로 하면 메모리 기준 정렬

```
top -pid $(pgrep valkey-server)
```
→ valkey-server 프로세스 하나만 콕 집어서 실시간 감시

간단히는 아까처럼
```
ps aux | grep valkey-server
```
로 한 번 스냅샷만 봐도 됩니다 (`%CPU`, `%MEM` 컬럼).

지금 활동 모니터 열어서 같이 확인해볼까요, 아니면 터미널 `top`으로 보여드릴까요?
