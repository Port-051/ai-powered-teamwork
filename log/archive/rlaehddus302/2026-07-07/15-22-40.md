### assistant


**Hermes란?** NousResearch/hermes-agent — 세션이 끝나도 기억이 유지되고, 쓸수록 스킬을 스스로 만들어 똑똑해지는 오픈소스(MIT) AI 에이전트. CLI로 설치해서 쓰고, Slack·Discord·Telegram 등 메신저에도 붙일 수 있는 "게이트웨이" 기능이 있음. 우리 프로젝트에서는 이 중 **개인별 기억(memory) 기능**만 엔진으로 가져다 쓸 계획이고, 팀 협업 지능 레이어는 우리가 직접 만듦(Hermes에는 없는 부분).

**학습 순서 (완전 처음이라는 전제로):**

1. **개념 훑기 (30분)** — https://hermes-agent.nousresearch.com/docs/ 에서 Overview + Memory 섹션만 읽기. "메모리가 세션 넘어 어떻게 유지되는지" 감만 잡으면 충분. 스킬 자동생성, 멀티플랫폼 연동 같은 나머지 기능은 지금 단계엔 몰라도 됨.

2. **직접 설치하고 CLI 만져보기**
   ```bash
   # 공식 설치 방법은 문서의 Getting Started 참고
   hermes doctor          # 설치/설정이 정상인지 진단
   ```
   `hermes doctor`가 통과하면 기본 세팅은 끝난 것.

3. **CLI로 대화해보며 기억 체감** — 터미널에서 `hermes`로 바로 대화 몇 번 나눠보고, 세션을 새로 열어도 이전 대화를 기억하는지 확인. 개념보다 체감이 훨씬 빠름.

4. **CLI 레퍼런스 훑기** — https://hermes-agent.nousresearch.com/docs/reference/cli-commands 에서 `memory`, `session` 관련 명령어만 골라서 실행해보고, `~/.hermes/` 아래에 뭐가 저장되는지 직접 열어서 구조 확인.

5. **소스코드는 memory 부분만** — github.com/NousResearch/hermes-agent 를 통째로 읽지 말고, 메모리 저장·검색·요약 로직 쪽 코드만 골라서 보기. 나중에 "팀 협업 지능 레이어"가 이 개인 기억과 어떻게 연결될지 설계할 때 필요한 부분이 여기임.

6. **메신저 연동 감 잡기** — Hermes gateway로 Slack이든 뭐든 하나에 연결해서 "멘션 → 응답" 왕복을 직접 겪어보기. 이걸 겪어봐야 나중에 Mattermost 어댑터를 만들 때 "이 자리에 뭘 끼워 넣으면 되는지" 그림이 그려짐.

이 순서대로 하면 하루 안에 "Hermes가 뭘 하는 물건인지 + 우리 프로젝트에서 어디에 쓰이는지"까지는 감이 잡힐 겁니다.
