npm 워크스페이스
npm을 사용하여 워크스페이스와 상호 작용하려면(예: 종속성 추가 또는 스크립트 실행) --workspace`--` 또는 ` --workspaces--` 플래그를 사용하십시오. 이 플래그는 `npm install`과 같은 내장 npm 명령을 사용 npm add하거나 스크립트를 실행할 때 사용할 수 있습니다. 이러한 명령은 이 디렉터리에서 실행해야 합니다.

# Add a dependency to a single package
npm add react --workspace=playbooks

# Build multiple packages
npm run build --workspace=platform/client --workspace=platform/components

# Test all workspaces
npm test --workspaces

# Clean all workspaces that have a clean script defined
npm run clean --workspaces --if-present
워크스페이스에 필요한 종속성을 설치하려면 npm install이 폴더에서 평소처럼 명령을 실행하기만 하면 됩니다. 대부분의 패키지 종속성은 루트 폴더에 포함되며 node_modules, 모든 패키지의 종속성은 하위 폴더에 나타납니다 package-lock.json. 하위 폴더는 node_modules패키지의 종속성 중 하나가 다른 패키지의 종속성과 충돌하는 경우에만 생성됩니다.
