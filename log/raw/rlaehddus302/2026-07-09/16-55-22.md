## 왜 "제한이 없다"고 느껴지는가

몇 가지 이유가 있습니다:

1. **숫자를 눈에 띄게 안 보여줌** — API처럼 "429 에러, 한도 초과"라고 딱 잘라 막는 게 아니라, **한도를 넘으면 조용히 더 약한 모델(mini)로 슬쩍 바꿔치기**합니다. 그래서 사람은 "어? 답이 좀 부실해졌네" 정도로만 느끼고 "막혔다"고 느끼지 못합니다.
2. **평범한 개인 사용 패턴으로는 하루 30~50건을 웬만해선 안 채웁니다.** 사람이 브라우저로 하루 종일 타이핑해도 그 정도 도달하기 어려워서 "느껴본 적이 없어서 없는 줄 아는 것"에 가깝습니다.
3. 반면 **봇/자동화 프로그램**은 순식간에 그 숫자를 넘길 수 있어서, 이게 바로 지난번 설명한 "왜 회사가 웹 세션 재사용을 막는가"의 이유와 정확히 연결됩니다 — 사람 기준으로 설계된 한도라 봇이 쓰면 몇 분 안에 다 씁니다.

## 정리

"웹 채팅 무료는 제한이 없다"는 건 잘못된 인식이고, 실제로는 **Gemini 웹 하루 30건, ChatGPT 웹 하루 약 40~50건 수준의 명확한 한도**가 있습니다. 다만 API 무료 티어(Gemini API 하루 1,500건)보다 오히려 웹 채팅 쪽 한도가 훨씬 작다는 게 흥미로운 지점입니다 — "API가 더 짜다"는 일반적 통념과 반대로, 최소한 Gemini는 **개발자용 API 무료 티어가 사람용 웹 무료보다 오히려 더 후합니다.**
