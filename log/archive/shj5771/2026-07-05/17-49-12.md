from collections import deque
queue = deque()
def solution(cacheSize, cities):
    result = 0
    
    
    for i in cities:
        i=i.lower()
        if i in queue:
            result += 1
            queue.pop("i")
            queue.append("i")
        else:
            result += 5
            queue.append("i")
            
            if len(queue)>cacheSize:
                queue.popleft()
    
    return result

이번엔 `queue.pop("i")`에서 에러 나요.

`deque`의 `pop()` 메서드는 리스트(list)와 달리 **인자를 받지 않아요.** 리스트의 `list.pop(index)`처럼 "특정 값이나 인덱스를 지정해서 제거"하는 기능이 없고, deque의 `pop()`은 무조건 **오른쪽 끝 원소 하나만** 제거하도록 설계돼 있어요 (왼쪽 끝은 `popleft()`).

그래서 `queue.pop("i")`처럼 인자를 넣으면:
```
TypeError: pop() takes no arguments (1 given)
```
이 뜹니다.

고치려면 인자 없이 `queue.pop()`이라고만 써야 하는데, 참고로 지금 로직상 "캐시 히트한 도시를 큐 중간에서 제거하고 맨 뒤로 옮기는" 걸 하고 싶으신 것 같은데, deque의 `pop()`은 무조건 오른쪽 끝만 제거하니 원하는 위치의 값을 지울 수가 없어요. 그 부분은 `queue.remove(i)`를 쓰셔야 특정 값을 찾아서 제거할 수 있습니다.
