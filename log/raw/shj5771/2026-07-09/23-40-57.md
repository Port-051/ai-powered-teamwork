네, 훨씬 편해요 — Node.js나 Homebrew 설치 없이 딱 한 줄이면 돼요. 아까 드린 방법(Homebrew → Node.js → npm)은 그냥 넘어가시고 이걸로 하세요.

**터미널에 아래 명령어 복붙하고 Enter**
```
curl -fsSL https://claude.ai/install.sh | bash
```

**복붙하는 법** (방금 배우신 거 그대로)
1. 위 코드를 마우스로 드래그해서 선택
2. `Command + C`
3. 터미널 클릭 → `Command + V`
4. `Enter`

설치 끝나면 확인:
```
claude --version
```

버전 숫자 나오면 설치 완료예요. 그 다음은 아까 안내드린 대로 `git clone`으로 이 레포 받고 `git config user.name` 설정한 뒤 `claude` 실행하시면 됩니다.
