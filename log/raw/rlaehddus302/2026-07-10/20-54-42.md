멀티플렉싱을 끄는 명령어는 이겁니다.

```bash
hermes config set gateway.multiplex_profiles false
hermes gateway restart
```

(켤 때 썼던 `hermes config set gateway.multiplex_profiles true`의 반대로, `true`를 `false`로 바꾸고 `gateway restart`로 반영하면 됩니다. default 프로파일에서 실행해야 합니다 — 멀티플렉서를 소유한 게 default 프로파일이라서요.)

다만 이전 답변대로 실제로 끌 필요는 없고, 원하시면 그냥 켠 채로 `hermes profile delete <name>` → `hermes gateway restart`만 해도 됩니다. 그래도 끄고 진행하고 싶으시면 이 명령어 실행할까요?
