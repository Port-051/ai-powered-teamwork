공식 문서(`website/docs/reference/profile-commands.md`) 기준입니다.

```bash
hermes profile delete <name>
# 확인 프롬프트 없이 바로 지우려면
hermes profile delete <name> --yes
```

주의할 점:
- **현재 활성화된(active) 프로파일은 삭제 불가**입니다. 지우려면 먼저 다른 프로파일로 전환해야 합니다: `hermes profile use default` 같은 식으로요.
- 삭제하면 그 프로파일 디렉터리 전체(설정, 메모리, 세션, 스킬 포함)가 **영구 삭제**됩니다 — 되돌릴 수 없으니, 지우기 전에 혹시 남겨야 할 내용이 있다면 `hermes profile export <name>` 으로 tar.gz 백업부터 떠두는 걸 추천합니다.
- 실제로 삭제 명령을 실행하기 전에 어떤 프로파일을 지울지 저한테 알려주시면, 실행 전에 다시 한 번 확인 여쭤보고 진행하겠습니다.
