결론부터 정리하면, 다음 순서로 하면 삽질 없이 한 번에 됩니다:

1. **Hermes 설치**: `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`
2. **Slack 앱 생성**: manifest 파일(`unho/slack-manifest.json`)로 한 번에 만들기 — 이게 스코프/이벤트/Socket Mode를 다 미리 채워줘서 우리처럼 하나씩 놓치는 실수가 없음
3. **토큰 2개 발급**: Basic Information → App-Level Token(`xapp-`), OAuth & Permissions → Install to Workspace 후 Bot Token(`xoxb-`)
4. **`hermes setup gateway`**로 토큰 등록 (또는 `.env` 직접 편집)
5. **모델을 무료로 맞추기** (카드 등록 피하려면 이게 핵심):
   ```bash
   hermes config set model.provider openrouter
   hermes config set model.default "nvidia/nemotron-3-super-120b-a12b:free"
   ```
6. `hermes gateway install` + `hermes gateway start`로 백그라운드 등록
7. Slack에서 봇 채널 초대 → 멘션해서 확인

이게 팀 전체가 겪을 수 있는 문제(스코프 빠뜨림, 이벤트 구독 안 함, 결제 에러)를 미리 피하는 순서라, `shared/`에 올리는 게 맞다고 봐요 — `hongjae/`, `unho/`는 "각자 겪은 기록"이고 `shared/`는 "팀이 따라야 할 정리된 가이드" 용도로 나눠뒀으니까요.
