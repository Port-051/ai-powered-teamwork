### user
지금 멀티프파일 했는데 hermes명령어로 지금 profile이 몇 개 있는 지 알 수 있는 방법 있나?

### assistant
`hermes profile list`

```bash
hermes profile list
```

지금 만들어진 profile 전부(현재 활성화된 건 `*` 표시)와 각각의 모델/게이트웨이 상태까지 같이 보여줍니다. 예:

```
  default
* dongyeon
  unho
  hongjae
```

멀티플렉싱 켜둔 상태에서 각 profile의 게이트웨이가 실제로 잘 서빙되고 있는지까지 보고 싶으면:

```bash
hermes gateway list
```

이건 전체 profile 목록 + 각 profile의 게이트웨이 running/stopped 여부(가능하면 PID까지) 같이 보여줍니다.
