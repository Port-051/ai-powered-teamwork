### user
hermes gateway 시작 명령어가 뭐지?

### assistant


WSL 환경이시니 `start`보다 `run`을 쓰는 게 맞습니다 (WSL은 systemd 서비스 지속성이 불안정해서 지난번에도 그래서 "n"으로 답하신 거였죠).

```bash
hermes gateway run
```

**멀티플렉싱 켜신 상태**라면, default profile에서 이 명령 하나만 실행하면 됩니다 — dongyeon/unho/hongjae는 이 안에서 같이 서빙됩니다. (개별 profile에서 `<name> gateway run`은 하시면 안 됨 — "이미 멀티플렉서가 서빙 중"이라는 에러 남.)

터미널 창 닫아도 계속 돌아가게 하려면 tmux에 넣어서 실행하세요:
```bash
tmux new -s hermes 'hermes gateway run'
```
나중에 다시 들여다보고 싶으면 `tmux attach -t hermes`.

(참고로 `hermes gateway start`는 systemd 서비스로 등록해서 백그라운드로 띄우는 거라, 방금 "자동 시작 n"으로 답하신 것과 같은 계열입니다 — WSL에선 권장 안 함.)
