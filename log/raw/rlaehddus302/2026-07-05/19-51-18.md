## 남는 돈 활용법 (좋은 순서대로)

**1순위: 맥미니 저장공간(SSD)을 키운다 — 512GB → 1TB**
- 애플 SSD도 **나중에 내장은 못 늘려.** RAM 다음으로 미리 사두면 좋은 것.
- 사진·프로젝트·로컬 LLM 모델 파일(한 개에 몇 GB~수십 GB) 쌓이면 512GB는 금방 참.
- 맥 구성 옵션이라 지원 품목에 포함됨.

**2순위: 좋은 모니터 하나 제대로 — 27~32" 4K USB-C**
- 지금 M4로 칩값을 아끼는 대신, **오래 쓸 모니터에 투자**하는 게 균형이 맞아. 모니터는 컴퓨터 몇 번 바꿔도 계속 씀.
- **USB-C(썬더볼트) 모니터로 고르면 갤럭시북도 케이블 하나로 연결** 가능 → 맥이든 노트북이든 이 모니터 하나로 다 씀. 일석이조.
- 예: 27" 4K USB-C(50~70만) 또는 32" 4K(70~90만).

**3순위: 듀얼 모니터 (모니터 2대)**
- 개발할 땐 화면 2개가 생산성에 진짜 큼(코드/실행결과 나눠 보기). 27" 두 대도 지원 품목상 가능.
- 다만 저장공간(1TB)부터 챙기고 남으면 이쪽.

## 솔직한 한마디

이렇게 하면 **총액은 M4 Pro안이랑 거의 똑같은 ~300만원**이 돼. 결국 선택은:
- **M4 Pro + 기본 모니터** (강한 칩 / 화면은 평범)
- **M4 일반 32GB/1TB + 좋은 모니터** (칩은 평범 / 저장공간·화면 좋음)

둘 다 예산은 똑같이 채워. **"성능(칩)이냐, 저장공간+화면이냐"**의 취향 차이일 뿐이야. 로컬 LLM 속도까지 챙기고 싶으면 M4 Pro, 그게 그렇게까지 중요하진 않고 넉넉한 저장공간·좋은 화면이 더 끌리면 이 M4 일반 구성이 아주 합리적이야.
