공식 문서/AWS re:Post 기준으로 확인된 원인은 두 가지입니다.

1. **저장 안 된 신규 배포일 가능성** — 지역 제한(Geographic restrictions)은 CloudFront 배포를 **생성 후 저장한 뒤**에만 Security 탭에 나타납니다. 배포 생성 마법사 도중이거나 아직 저장 전이면 이 항목이 안 보입니다.
2. **배포 생성 시 오리진 타입을 "Others"(Lightsail 등 CloudFront/S3/ALB가 아닌 커스텀 오리진)로 선택한 경우** — AWS re:Post에 실제로 보고된 사례로, 이 경우 Security 탭에 "CloudFront geographic restrictions" 항목 자체가 나타나지 않는다는 문의가 있습니다 (Lightsail 오리진 케이스).

정상 경로는: 배포 선택 → **Security 탭** → "CloudFront geographic restrictions" 섹션 펼치기 → Edit. 이 경로 자체는 최신 콘솔에서도 유효합니다.

확인해보실 것: 배포를 만들 때 오리진으로 뭘 선택하셨는지(S3/커스텀 HTTP 오리진 vs Lightsail/기타), 그리고 배포가 "Deployed" 상태로 완전히 저장됐는지 확인해보세요.
