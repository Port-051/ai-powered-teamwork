**Codex CLI(터미널에서 쓰는 코딩 에이전트, Claude Code랑 비슷한 포지션)는 오픈소스예요** — Apache-2.0 라이선스, `github.com/openai/codex`에 공개되어 있어요. Rust로 만들어졌고 2026년 4월 기준 GitHub star 7만 4천개 정도예요.

다만 여기서도 앞서 Hermes 얘기했던 것과 똑같은 구분이 적용돼요:

- **Codex CLI(도구 자체)**: 오픈소스, 자유롭게 포크·수정 가능
- **실제로 코드를 생성하는 AI 두뇌(모델 추론)**: OpenAI 서버에서 돌아가는 비공개 모델이라, OpenAI 계정으로 API 호출해야 하고 그만큼 비용이 발생해요

즉 "도구는 오픈소스, 그 도구가 부르는 모델은 비공개"인 구조는 Hermes 때 봤던 패턴이랑 완전히 똑같아요.
