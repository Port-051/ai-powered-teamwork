**로그인할 때 입력한 아이디 = 보통 이메일 주소**
IAM Identity Center는 대부분 **이메일 주소 자체를 로그인 아이디(사용자명)로** 씁니다. 즉:

```
아이디: shj5771@naver.com
비밀번호: 방금 재설정하신 새 비밀번호
```

**"Port_051"은 아이디가 아니라 표시 이름(display name)**
우측 상단에 뜨는 `Port_051`은 로그인 아이디가 아니라, 관리자가 이 계정에 붙여준 **팀/사용자 표시 이름**이에요. 실제 로그인 창에 입력하는 값은 이메일(`shj5771@naver.com`)이고, 로그인 성공 후 화면에 "당신은 Port_051입니다"라고 보여주는 것뿐입니다.

**정리**: 로그인 아이디 = `shj5771@naver.com` (이메일), 비밀번호 = 아까 재설정한 것. 이미 이 조합으로 로그인 성공하신 거예요. 나중에 다시 로그인할 때도 이 이메일 그대로 쓰시면 됩니다.
