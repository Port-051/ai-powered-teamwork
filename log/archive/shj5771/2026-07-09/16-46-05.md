### assistant






Hermes Agent 자체(코드)는 완전 무료·오픈소스(MIT)라 라이선스 비용은 없어요. 유료 요소는 **Nous Portal**이라는 별도 구독 서비스인데, 이건 "모델 API를 몰아서 편하게 쓰게 해주는" 서비스예요.

**무료 티어**
- 월 $0, 대신 $10부터 시작하는 종량제(pay-as-you-go) 크레딧을 충전해서 씀 (1:1 환산)
- 간단히 테스트해보는 수준엔 충분하지만, 실사용(real workload)엔 부족
- **Tool Gateway**(웹검색·이미지생성·TTS·브라우저 자동화 같은 내장 도구) 미포함

**유료 플랜 (Nous Portal 구독)**
| 플랜 | 월 요금 | 매달 지급 크레딧 |
|---|---|---|
| Plus | $20 | $22 |
| Super | $100 | $110 |
| Ultra | $200 | $220 (+ 가장 높은 요청 한도) |

- 300개 이상의 모델을 하나의 결제로 묶어 쓸 수 있음
- Tool Gateway(웹검색·이미지생성·TTS·브라우저 자동화) 4종 도구 포함
- 요청 한도(rate limit)가 플랜별로 다름 — Ultra가 가장 넉넉함

**저희 프로젝트 관점에서 중요한 점**: 이건 Hermes 코드 라이선스랑 무관한, **모델 API 이용료 서비스**예요. 저희는 Nous Portal을 안 쓰고 우리가 원하는 다른 LLM API(OpenRouter, OpenAI 등)를 붙여도 되니까, 이 구독 자체가 우리 사업모델에 직접 영향 주진 않아요 — 그냥 팀원이 개인적으로 편하게 쓰려면 참고할 옵션 정도입니다.
