## 1. "Telegram에서 Discord로 옮겨도 문맥이 안 끊긴다" — 정정합니다

다시 문서를 확인해보니 이건 제가 잘못 전달했습니다. **실제로는 플랫폼을 넘어가면 세션이 이어지지 않습니다.** 세션은 플랫폼별로 완전히 분리되어 있고, `/resume [이름]` 같은 명령으로 예전 세션을 다시 불러오는 것도 **같은 플랫폼 안에서만** 가능합니다. 허용 목록도 `TELEGRAM_ALLOWED_USERS`, `DISCORD_ALLOWED_USERS`처럼 플랫폼마다 따로 관리되고, 플랫폼을 넘나드는 통합 사용자 식별 장치는 없습니다.

즉 정리하면: **"대화방 = 세션 단위"라는 게 플랫폼 안에서의 얘기지, 플랫폼을 넘어서까지 통합되는 건 아닙니다.** Telegram에서 봇과 나눈 대화는 Telegram만의 세션이고, Discord로 옮기면 완전히 새 세션으로 시작합니다. 헷갈리게 말씀드려서 죄송합니다.

## 2. "자체 제공하는 모델 게이트웨이"가 뭔가

Nous Research가 자체적으로 만든 LLM을 말하는 게 아닙니다. **Nous Portal은 결제/라우팅 대행 서비스**입니다 — 실제로는 뒤에서 OpenRouter를 통해 Claude, GPT, Gemini, DeepSeek, Qwen 같은 **다른 회사들의 진짜 프론티어 모델**에 연결해주고, 사용료만 "Nous 구독"이라는 하나의 창구로 묶어서 청구하는 방식입니다. 비유하면 여러 통신사 요금을 하나의 알뜰폰 재판매업체가 대신 청구해주는 것과 비슷합니다. 그래서 Hermes 안에서 `/model anthropic/claude-sonnet-4.6`처럼 모델을 골라 쓸 수 있는 거고, Claude·Gemini API 키를 각각 따로 안 만들어도 되는 게 이 서비스의 장점입니다.

## 3. "Claude·Gemini가 Hermes로 쓰이는 걸 싫어해서 걸리면 삭제한다"는 얘기

여기서 중요한 구분이 있습니다 — **"어떻게 연결하느냐"에 따라 완전히 다른 얘기**입니다.

- **정식 API 키(종량제 결제)로 연결** — 이건 Anthropic/Google이 애초에 그러라고 만든 공식 창구입니다. Hermes 같은 에이전트 프레임워크가 API를 호출하는 건 API의 정상적인 용도이고, 이것만으로 계정을 정지시키는 일은 없습니다. Nous Portal도 결국 OpenRouter를 거쳐 이 정식 API 경로로 붙는 것이라 여기 해당합니다.
- **개인 구독 로그인(예: claude.ai 웹 로그인 세션, Gemini 앱 로그인)을 비공식적으로 재활용해서 API처럼 쓰는 것** — 이건 실제로 약관 위반이고, Anthropic/Google이 이런 패턴을 탐지해서 계정을 정지시키는 사례가 실제로 있습니다. 아마 들으신 얘기는 이쪽(웹 구독 계정을 API처럼 우회해서 쓰는 방식)에 대한 것일 가능성이 높습니다.

**그래서 Hermes 자체가 연결이 불가능한 건 아니고, 정식 API 키(또는 Nous Portal처럼 정식 API를 대행하는 창구)로 연결하면 문제없습니다.**

다만 이건 저희 PLAN.md Phase 8에 있는 "초기 유저는 Claude/Codex 등 **유료 구독** 보유자 위주라 초반 비용 부담은 크지 않을 것"이라는 가정과 살짝 충돌할 수 있는 부분입니다 — 만약 "유료 구독"이 claude.ai 웹 구독(Claude Pro 등)을 의미하는 거라면, 그걸 Hermes 같은 에이전트에 그대로 재활용하는 건 위에서 말한 "위험한 쪽"에 해당할 수 있고, 정식 API 키(별도 종량제 결제)를 쓰는 것과는 다른 문제입니다. 이 부분은 실제 구현 전에 한 번 짚고 넘어가면 좋을 것 같습니다 — 필요하시면 PLAN.md 열린 질문에 메모해드릴까요?
