## 슬랙 설치 (Windows 11 기준)

### 1단계 — 워크스페이스(우리 팀 공간) 만들기
1. 브라우저에서 **`https://slack.com/get-started`** 접속 → **"워크스페이스 만들기"** 클릭
2. 이메일 입력 → 메일로 온 6자리 코드 입력
3. 워크스페이스 이름 정하기 (예: `Port_051`)
4. 팀원(여운호·신홍재) 이메일 초대 — 나중에 해도 됨
5. 첫 채널 이름 정하기 (예: `#general`)
6. 완료되면 `포트051.slack.com` 같은 우리 팀 주소 생성됨

> 만든 사람(김동연님)이 관리자(오너)가 돼요.

### 2단계 — 데스크톱 앱 설치
- **`https://slack.com/downloads/windows`** 에서 설치 파일 받아 실행
- 또는 Microsoft Store에서 "Slack" 검색 → 설치
- 앱 실행 후 → 만든 워크스페이스 주소로 로그인

### 3단계 — 핵심 기능 5개만 만져보기

| 기능 | 뭐냐 | 어떻게 |
|---|---|---|
| 채널(Channel) | 주제별 단체 대화방 | 왼쪽 `+` → "채널 만들기" |
| DM | 1:1 개인 메시지 | 왼쪽 "Direct Messages"에서 상대 선택 |
| 멘션(@) | 특정 사람 콕 부르기 | 메시지에 `@이름` 입력 |
| 스레드(Thread) | 한 메시지에 달린 답글 묶음 | 메시지에 마우스 올리면 "스레드로 답장" |
| 봇/앱(App) | 자동응답 프로그램 | 나중에 Hermes 봇 붙일 자리 (지금은 구경만) |

**꼭 해볼 것**: 채널 만들기 → `@`로 팀원 부르기 → 아무 메시지에 스레드 답글 달기. 이 세 개가 우리 제품 UX의 뼈대예요.

### 참고
- 무료 플랜은 최근 90일치 메시지만 보여요 — 연습용으론 문제없어요.
