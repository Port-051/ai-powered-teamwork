AWS MFA(Multi-Factor Authentication, 다단계 인증)는 AWS 계정에 로그인할 때 **아이디/비밀번호 외에 한 단계를 더 요구하는 보안 장치**예요.

**동작 방식**: 로그인 시 비밀번호 입력 후, 스마트폰 앱(Google Authenticator, Authy 등)이나 하드웨어 키가 보여주는 **6자리 숫자 코드**를 추가로 입력해야 로그인이 완료됩니다. 이 코드는 30초마다 바뀌어요.

**왜 필요한가**: 비밀번호만 뚫리면(유출·추측) 누구나 로그인할 수 있는데, MFA를 켜두면 비밀번호를 알아도 실제 스마트폰(또는 키)이 없으면 못 들어갑니다. 특히 **루트 계정(AWS 가입 시 만든 최상위 관리자 계정)**은 AWS가 MFA를 강력 권장/사실상 필수로 취급해요 — 루트 계정이 털리면 결제 정보까지 포함해서 계정 전체가 위험해지기 때문.

**종류**:
- **가상 MFA**: 스마트폰 앱으로 코드 생성 (가장 흔함, 무료)
- **하드웨어 MFA**: 실물 보안키(YubiKey 등)
- **SMS MFA**: 문자로 코드 받기 (보안성이 상대적으로 낮아 잘 안 씀)

**설정 위치**: AWS 콘솔 → IAM(계정 관리 서비스) → 사용자/보안 자격 증명 → MFA 디바이스 할당.
