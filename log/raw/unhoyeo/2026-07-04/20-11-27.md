<result>## Session Naming in Claude Code

**Yes, this is fully supported.** There are three ways to name or rename a background job session:

### At Startup
```bash
claude -n my-task-name
```
or
```bash
claude --name my-task-name
```

### During an Active Session
Use the `/rename` command:
```
/rename my-task-name
```
The name appears on the prompt bar and in session listings.

### From the Session Picker
1. Run `claude --resume` (or `/resume` inside a session)
2. Navigate to your session
3. Press `Ctrl+R` to rename it interactively

### Resume by Name
Once named, resume the session directly:
```bash
claude --resume my-task-name
```

### Default Names
If you never explicitly name a session, Claude Code v2.1.196+ automatically assigns a default display name combining your directory name with a two-character suffix (e.g., `my-app-3f`), visible in agent view and `claude agents --json` output—but you can't use this default to resume; only explicit names work with `--resume`.

The named session will appear descriptively in your job list instead of generic auto-generated names.
