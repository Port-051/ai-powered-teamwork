## ChatGPT — "mini로 전환"도 결국 한도 안에 있습니다

검색 결과 명확한 결론:
> **"The GPT-4o-mini fallback is not truly unlimited—it's simply what you get after exhausting your GPT-4o message allowance. Free users remain subject to rolling time-window limits on both the primary model and the fallback."**

즉 강한 모델(GPT-4o) 한도를 넘으면 mini로 바뀌긴 하지만, **그 mini도 시간이 지나면 다시 리필되는 롤링 윈도우 한도 안에서 도는 것**이지 "이제부터 완전 무제한"이 되는 게 아닙니다. "약한 모델 = 무제한"이 아니라 "약한 모델 = 조금 더 여유로운 한도"에 가깝습니다.

## Gemini — 오히려 더 단호합니다

> **"Once you hit your RPD limit, you're done for the day... no automatic fallback to a less capable model. The API simply blocks further requests"**

Gemini는 아예 **약한 모델로 자동 전환하는 기능 자체가 없습니다.** 한도를 넘으면 그냥 그날은 끝 — 다음날 자정(태평양시간)까지 완전히 막힙니다.

## 정리

| | 한도 넘으면? |
|---|---|
| ChatGPT 웹 무료 | 더 약한 모델(mini)로 전환되지만, **그것도 자체 시간당 한도가 있음** |
| Gemini | 자동 전환 없음, **그냥 완전 차단**, 자정까지 대기 |

"약한 모델로 하면 공짜(무제한)"라는 인식은 실제 정책과 다릅니다. 두 회사 다 **결국 어떤 형태로든 한도가 존재**하고, 그 한도를 없애는 유일한 방법은 결제뿐입니다. 이게 바로 지난번 결론(Gemini API 무료 티어 하루 1,500건 같은 명시적 한도를 기준으로 설계해야 한다)이 그대로 맞다는 뜻입니다 — "무제한 구멍"은 어디에도 없습니다.
