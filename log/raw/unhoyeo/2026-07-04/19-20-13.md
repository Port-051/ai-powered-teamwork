구글 캘린더 API를 세팅하는 방법에는 두 갈래가 있어요:

**방법 A: MCP 서버 연결 (추천 — 이 세션에서 바로 캘린더 도구를 쓸 수 있게 됨)**
Claude Code에 구글 캘린더용 MCP 서버(다른 서비스와 연결해주는 플러그인 같은 것)를 붙이는 방식이에요. 이러면 제가 "일정 추가해줘" 요청을 실제로 실행할 수 있는 도구를 갖게 됩니다.

**방법 B: 구글 클라우드 콘솔에서 직접 API 키/OAuth 발급**
구글 개발자 콘솔에 프로젝트를 만들고 Calendar API를 켠 뒤, OAuth 인증 정보를 받아서 스크립트를 직접 짜는 방식이에요. 더 번거롭지만 나중에 실제 TeamBrain 프로젝트에 붙일 코드를 미리 연습해볼 수 있다는 장점이 있어요.

지금은 "간단 테스트"가 목적이시니 방법 A가 훨씬 빠를 것 같아요.
