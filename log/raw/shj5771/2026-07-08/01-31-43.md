### assistant


Postgres는 외부 포트가 안 열려 있어서, 컨테이너 안에 직접 들어가서 확인해야 합니다 (`docker exec`로 컨테이너 내부에서 명령 실행).



이렇게 접속됩니다 (`docker exec [컨테이너이름] psql -U [계정] -d [DB이름]`로 컨테이너 안 postgres에 SQL 명령 실행). 방금 테이블 목록만 뽑아봤는데, `users`, `channels`, `posts` 같은 실제 데이터 테이블들이 다 보이네요.

원하시면:
- **가입된 유저 확인**: `docker exec shared-postgres-1 psql -U mmuser -d mattermost -c "SELECT username, email FROM users;"`
- **직접 들어가서 자유롭게 조회**: `docker exec -it shared-postgres-1 psql -U mmuser -d mattermost` (대화형 SQL 창)
