### assistant










문서와 이전 메모리 내용(`gateway restart` 시점마다 그 순간 존재하는 모든 profile을 새로 enumerate)을 종합하면 —

**꺼지 않아도 됩니다.** 순서 상관없이:

```bash
hermes profile delete <name>
hermes gateway restart
```

이렇게만 해도 됩니다. 이유:
- 멀티플렉서(default 프로파일의 게이트웨이)는 `gateway restart` 할 때마다 그 시점에 존재하는 profile들을 다시 훑어서(enumerate) 구동합니다. 삭제된 profile은 다음 restart부터 자연스럽게 목록에서 빠집니다.
- 단, `hermes profile delete`는 **현재 active profile은 삭제 불가**라는 제약은 그대로 적용됩니다. 지울 프로파일이 지금 활성 상태면 먼저 `hermes profile use default`로 바꾼 뒤 삭제해야 합니다.
- 삭제 자체는 멀티플렉싱 켜져 있는 것과 무관하게 실행되고, 삭제 후 `hermes gateway restart` 한 번만 해주면 멀티플렉서가 새 상태를 반영합니다.

정리하면: 멀티플렉싱은 끌 필요 없고, `hermes profile delete <name>` → `hermes gateway restart` 순서면 충분합니다. 지울 프로파일 이름 알려주시면 실행 전에 다시 확인 여쭙고 진행하겠습니다.
