## 지금 만든 것 = "멘션 → Claude 한 번 호출 → 답장" 딱 그거

`bot.py`에 Claude API를 붙이면 이렇게 돼요:

```python
@app.event("app_mention")
def handle_mention(event, say):
    text = event["text"]
    response = client.messages.create(model="...", messages=[{"role": "user", "content": text}])
    say(response.content[0].text)
```

이건 **"그 순간 친 메시지 한 줄"만 Claude에게 넘기고 답 받아오는 것**이에요. 여기엔 이런 게 전혀 없어요:
- ❌ **팀이 예전에 뭘 얘기했는지 기억** — Claude는 매번 완전히 처음 보는 사람처럼 답해요 (이 API 호출은 "1회성"이라, 이전 대화를 전혀 몰라요)
- ❌ **다른 사람이 뭘 물어봤는지 파악** — 그냥 지금 멘션한 사람 텍스트 하나만 보고 답하는 거예요

## "Slack AI"랑 비교하면

**Slack AI**는 슬랙 회사가 직접 만들어서 파는 **유료 기능**이에요 (우리가 코드로 만드는 게 아니라, 설정 켜면 자동으로 워크스페이스 전체 대화 기록을 요약·검색해주는 기능). 지금 만든 건 그거랑도 달라요 — 오히려 이건 **"슬랙에 챗봇 하나 붙인 것"**에 가까워요 (이미 시중에 있는 ChatGPT-슬랙 연동 앱들이랑 비슷한 수준).

## 우리가 얘기했던 "팀 공유 지능"이 되려면 뭐가 더 필요한가

| 지금 있는 것 | 필요한 것 |
|---|---|
| 멘션 → Claude 호출 → 답장 | ✅ 있음 |
| 이전 대화 기억 (세션 유지) | ❌ 없음 — Hermes가 하는 일 |
| "다른 사람이 뭘 물었는지" 검색해서 답에 반영 | ❌ 없음 — 채널 검색 API 붙이고, 그 결과를 Claude 호출할 때 같이 넣어줘야 함 |

## 그래도 의미는 커요

**"멘션 감지 → AI 호출 → 답장" 왕복이 실제로 되는 걸 손으로 확인했다는 것 자체가 중요한 첫 성공**이에요. 우리 프로젝트의 ①어댑터가 하는 일이 정확히 이거고, 이게 되니까 다음 단계(과거 대화 검색해서 같이 넣어주기)로 넘어갈 준비가 된 거예요.
