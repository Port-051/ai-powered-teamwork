# TeamBrain

> 팀의 지식과 의사결정을 기록하고, LLM과 함께 탐색·정리하는 Git 기반 팀 위키입니다.

**Port_051 · SW Maestro 17기 (부산)**  
팀원: 신홍재  · 김동연 · 여운호

## 소개

이 저장소는 TeamBrain 프로젝트를 진행하며 쌓이는 정보를 팀의 공유 지식으로 남기기 위한 **LLM 위키**입니다.

프로젝트 기획, 회의 내용, 기술 검토, 실험 결과, 의사결정의 배경을 문서로 축적하고, 이를 LLM이 참고할 수 있는 공통 맥락으로 활용합니다.

단순히 “무엇을 했는가”만 기록하는 것이 아니라, **“어떤 문제가 있었고, 무엇을 비교했으며, 왜 그렇게 결정했는가”**까지 남기는 것을 지향합니다.

## 왜 필요한가

프로젝트의 중요한 정보는 대화, 개인 메모, 각자의 AI 대화창에 흩어지기 쉽습니다. 결과만 남기면 당시의 판단 근거를 다시 찾기 어렵고, 이미 논의한 내용을 반복해서 설명해야 합니다.

이 저장소는 팀의 정보가 일회성 대화로 사라지지 않도록 기록하고, 개인이 알고 있던 맥락을 팀 전체가 다시 활용할 수 있는 지식으로 남기기 위해 운영합니다.

## LLM 위키로 활용하는 방식

저장소에 축적한 문서를 LLM의 참고 자료로 활용합니다. 프로젝트의 배경을 파악하거나, 이전 논의와 결정의 근거를 찾고, 여러 기록을 연결해 내용을 정리하는 데 활용하는 방식입니다.

새로운 논의와 실험에서도 결과뿐 아니라 판단 과정을 함께 기록하여, 다음 작업에서 다시 참고할 수 있는 맥락으로 남깁니다.

핵심은 **AI와 나눈 대화 자체를 쌓는 것이 아니라, 팀이 다시 사용할 수 있는 지식을 남기는 것**입니다.

## 문서 작성 원칙

- **맥락과 근거를 함께 기록합니다.** 결론뿐 아니라 문제 상황, 검토한 대안, 선택 이유와 관련 자료를 남깁니다.
- **사실과 제안을 구분합니다.** 확정된 결정, 검토 중인 아이디어, 아직 해결하지 못한 질문을 구분합니다.
- **LLM의 출력을 그대로 확정하지 않습니다.** 원문과 사실관계를 확인하고, 팀원이 검토한 내용을 위키에 반영합니다.

## 저장소 구성

- [`PLAN.md`](./PLAN.md) — 프로젝트 배경, 기획, 아키텍처 및 일정
- `submission/` — SW Maestro 제출용 초안 문서
- `experiments/` — 팀원별 기술 검토 및 실험 기록
- [`teambrain/reminder/`](./teambrain/reminder/README.md) — 리마인드 알림 기능의 구현 및 사용 문서
- `landing/` — 프로젝트 랜딩페이지

구현 코드와 실험 자료도 함께 보관하되, 이 저장소의 중심은 **팀의 지식과 의사결정 맥락을 축적하고 활용하는 것**입니다.
