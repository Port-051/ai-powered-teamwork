### assistant


Mattermost는 봇 계정을 관리자 화면에서 **완전히 삭제하는 기능 자체가 없고, "비활성화(Disable)"까지만** 지원합니다. 그래서 안 보이신 게 아니라, 원래 "삭제" 버튼이 없는 겁니다.

**1. 봇 비활성화 (관리자 화면에서 가능한 선)**

System Console → **Integrations → Bot Accounts** 로 들어가면 만들어둔 봇 목록이 뜹니다. 여기서 못 찾으셨다면:
- 상단 검색창에 봇 username(예: `hermes-dongyeon`) 입력해서 찾기
- 또는 **User Management → Users**에서 검색 (봇 계정도 내부적으론 유저라서 여기 나옴, "Bot" 태그가 붙어 보임)

찾으면 **Edit** 눌러서 **Disable** — 이러면 토큰이 즉시 무효화되고 더 이상 메시지 응답 안 함.

**2. 완전 삭제까지 하려면 서버 CLI 필요**

관리자 웹 화면엔 "삭제" 옵션이 없고, 서버에 SSH로 들어가서 `mmctl`(Mattermost CLI 도구)로 지워야 합니다:

```bash
mmctl user delete <봇-username>
```

(`mmctl`이 서버에 설치돼 있어야 하고, admin 토큰/로그인 필요)

**보통은 삭제까지 안 가고 비활성화만으로 충분**합니다 — 봇을 다시 안 쓸 거면 Disable, 나중에 재사용 가능성 있으면 그대로 두고 채널에서만 `/kick @봇이름`으로 빼면 됩니다.

어떤 상황이신가요 — 이 봇을 완전히 정리하고 싶으신 건가요, 아니면 그냥 채널에서 빼거나 잠깐 끄고 싶으신 건가요?
