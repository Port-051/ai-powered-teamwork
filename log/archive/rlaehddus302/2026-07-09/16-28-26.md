## 먼저: 무료 버전이어도 "웹 채팅 재활용"은 여전히 안 됩니다

지난번 설명한 약관 문제는 **유료냐 무료냐와 무관**합니다. `chatgpt.com`/`gemini.google.com`에 로그인해서 채팅하는 그 세션을, 우리 봇이 몰래 흉내내서 두드리는 건 무료 계정이어도 똑같이 금지·정지 사유입니다. "무료니까 상관없겠지"는 성립 안 합니다.

## 그런데 진짜로 공식적인 "무료 API"는 따로 있습니다 — 이게 핵심

### ① Google Gemini API 무료 티어 — 지금 당장 됨, Hermes가 이미 지원

이건 "웹 채팅 재활용"이 아니라 **Google이 개발자용으로 아예 공짜로 열어둔 정식 API 키**입니다. 신용카드도 필요 없습니다.

- Gemini Flash 계열: 분당 10건, **하루 1,500건**까지 완전 무료
- Hermes 소스에도 이미 정식 지원돼 있습니다 (`hermes_cli/auth.py:235-242`): `GEMINI_API_KEY`만 설정하면 끝

→ **셋 중 지금 당장 쓸 수 있는 가장 현실적인 무료 경로**입니다.

주의할 점: 무료 티어는 "입력·출력을 Google이 모델 개선에 쓸 수 있다"는 조건이 붙습니다 — 팀 대화가 민감한 정보라면 이 부분은 유의해야 합니다.

### ② OpenAI API 무료 티어 — 사실상 없다시피 함

지난번 Codex 얘기와 헷갈리기 쉬운데, **API 자체의 무료 티어는 2025년에 대부분 없어졌습니다.**
- 남은 건 "분당 3건, 그것도 구형 GPT-3.5-turbo만" 수준의 껍데기뿐
- 대부분 모델은 최소 **$5 선불 결제**를 해야 API 접근이 열립니다

→ OpenAI 쪽에서 "진짜 무료"를 기대하기는 어렵습니다.

### ③ Gemini CLI 개인 계정 로그인 — 하루 1,000건 무료, 그런데 Hermes가 아직 지원 안 함

Google도 OpenAI의 Codex CLI와 똑같은 방식이 있습니다: **`gemini` CLI**(Google 공식 도구)에 개인 구글 계정으로 로그인하면 **하루 1,000건까지 완전 무료** (신용카드 없이).

이게 지난번 설명한 "OpenAI 공식 도구 예외"와 완전히 같은 원리라 안전한 방법인데, **직접 확인해보니 Hermes 소스(`PROVIDER_REGISTRY`)에는 Gemini가 `auth_type="api_key"`로만 등록돼 있고, Codex처럼 CLI 로그인 토큰을 자동으로 빌려오는 기능은 없습니다.** (Codex는 `_import_codex_cli_tokens()`로 `~/.codex/auth.json`을 읽는 코드가 실제로 있지만, Gemini CLI의 `~/.gemini/...` 토큰을 읽는 대응 코드는 없음 — grep으로 확인.)

→ 이건 "안 되는 것"이 아니라 **"Hermes가 아직 안 만들어놓은 것"**입니다. 원리상 가능하고 오픈소스라 우리가 직접 이 연결을 추가하는 것도 가능은 하지만, 그럼 우리가 별도로 만들어야 할 작업이 됩니다.

## 정리

| 방법 | 무료인가 | 지금 Hermes로 되나 | 안전한가 |
|---|---|---|---|
| ChatGPT/Gemini 웹 무료판 세션 재활용 | 무료 | 기술적으론 시도 가능 | ❌ 약관위반(정지위험) |
| **Gemini API 무료 티어** | **무료** | **✅ 지금 바로 됨** | ✅ 안전 |
| OpenAI API 무료 티어 | 사실상 유료(최소 $5) | 됨 | ✅ 안전하나 무료 아님 |
| ChatGPT Free 요금제 + Codex CLI | 일부 무료 | ✅ 됨(토큰 재사용 기능 있음) | ✅ 안전 |
| Gemini CLI 개인계정 무료(1000건/일) | 무료 | ❌ 아직 미지원 | 원리상 안전, 구현 필요 |

**결론**: 비개발자 팀이 돈 안 내고 쓰고 싶다면, 지금 가장 현실적인 답은 **Gemini API 무료 티어(②)**입니다 — 지금 당장 Hermes로 바로 되고, 완전 합법이고, 하루 1,500건이면 소규모 팀 MVP 도그푸딩엔 충분할 수 있습니다. ChatGPT 계열로 무료를 원한다면 ③(Gemini CLI 통합)을 우리가 직접 만드는 게 다음 후보입니다.
