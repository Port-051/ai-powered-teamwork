스크린샷 붙여넣기가 안 되는데 왜 이렇지?

### assistant


터미널 환경(WSL + zsh)에서는 클립보드 이미지를 직접 붙여넣는 기능이 안 되는 경우가 많아요. Claude Code가 실행되는 곳이 어디냐에 따라 달라집니다.

## 원인

- **일반 WSL 터미널(zsh)**: 클립보드 이미지 붙여넣기 자체가 지원 안 됨
- 이미지 붙여넣기는 보통 **VS Code 통합 터미널**이나 특정 GUI 터미널(Windows Terminal 최신 버전 등)에서만 동작

## 대안 — 파일로 저장 후 경로 알려주기

1. Windows에서 캡처 도구(**PrtSc**, **Win+Shift+S** 등)로 스크린샷 찍기
2. 파일로 저장 (예: 바탕화면이나 아무 폴더)
3. 저장된 파일 경로를 저에게 알려주시면, 제가 `Read` 도구로 직접 읽을 수 있어요

Windows 경로면 이렇게 알려주시면 됩니다. 예:
```
C:\Users\kimye\Desktop\스크린샷.png
```
또는 WSL 경로 형태:
```
/mnt/c/Users/kimye/Desktop/스크린샷.png
```

캡처해서 저장하신 다음 경로만 알려주시면 바로 확인해드릴게요.
