좋아요, 봇/앱이 진짜 핵심이니 클릭 단위로 상세하게 갈게요. **Socket Mode**라는 방식을 쓸 건데, 이걸 쓰면 복잡한 서버 노출(ngrok 같은 것) 없이 내 컴퓨터에서 바로 테스트할 수 있어요.

> ⚠️ 하나만 먼저: 이건 **개인 연습용**이니, 발급받는 토큰(비밀키)은 이 프로젝트 폴더(`ai-powered-teamwork`)가 아니라 **별도의 개인 폴더**에서 작업하세요. 이 폴더에서 하면 로그 자동 기록 정책 때문에 토큰이 `log/raw`에 남을 수 있어요.

## 1단계 — 슬랙 앱(봇) 만들기

1. 브라우저에서 **`https://api.slack.com/apps`** 접속 (로그인 상태여야 함)
2. **"Create New App"** 버튼 클릭
3. **"From scratch"** 선택
4. App Name 입력 (예: `ai-bot-test`), **Pick a workspace** → 아까 만든 워크스페이스 선택
5. **"Create App"** 클릭 → 앱 관리 화면으로 이동됨

## 2단계 — Socket Mode 켜기 (서버 노출 없이 연습하기 위한 핵심)

1. 왼쪽 메뉴에서 **"Socket Mode"** 클릭
2. **"Enable Socket Mode"** 토글을 켬
3. 토큰 이름 입력창이 뜸 → 아무 이름(예: `socket-token`) 입력 → **"Generate"** 클릭
4. **`xapp-`로 시작하는 토큰**이 나옴 → 메모장 같은 데 복사해두기 (이게 **App Token**)

## 3단계 — 봇 권한(Scope) 설정

1. 왼쪽 메뉴에서 **"OAuth & Permissions"** 클릭
2. 아래로 스크롤 → **"Scopes"** → **"Bot Token Scopes"** 섹션
3. **"Add an OAuth Scope"** 클릭해서 아래 2개 추가:
   - `app_mentions:read` (누가 봇을 멘션했는지 읽는 권한)
   - `chat:write` (메시지 보낼 권한)
4. 페이지 맨 위로 스크롤 → **"Install to Workspace"** 버튼 클릭
5. 권한 확인 화면 나오면 **"Allow"** 클릭
6. 설치 완료되면 **`xoxb-`로 시작하는 토큰**이 보임 → 복사해두기 (이게 **Bot Token**)

## 4단계 — 멘션 이벤트 구독하기

1. 왼쪽 메뉴에서 **"Event Subscriptions"** 클릭
2. **"Enable Events"** 토글을 켬 (Socket Mode라서 Request URL 입력창은 안 나오고 그냥 켜짐)
3. 아래로 스크롤 → **"Subscribe to bot events"** 섹션
4. **"Add Bot User Event"** 클릭 → `app_mention` 검색해서 선택
5. **"Save Changes"** 클릭
6. 화면 위에 "재설치 필요" 알림 뜨면 → **"reinstall your app"** 링크 클릭 → 다시 Allow

이제 토큰 2개(`xoxb-...`, `xapp-...`)가 준비됐어요.

## 5단계 — 봇을 채널에 초대

1. 슬랙 앱으로 돌아가서 아무 채널이나 열기
2. `/invite @ai-bot-test` 입력 (앱 이름은 4단계 상관없이 만들 때 지은 이름)

## 6단계 — 코드 작성 (WSL 터미널에서)



WSL에 Python 3.10이 이미 있네요. 개인 연습용 폴더를 하나 만들어서 진행하면 됩니다.

```bash
mkdir -p ~/slack-bot-practice && cd ~/slack-bot-practice
pip3 install slack_bolt
```

`bot.py` 파일을 만들어서 아래처럼 작성:

```python
from slack_bolt import App
from slack_bolt.adapter.socket_mode import SocketModeHandler

BOT_TOKEN = "xoxb-여기에-복사한-Bot-Token"
APP_TOKEN = "xapp-여기에-복사한-App-Token"

app = App(token=BOT_TOKEN)

@app.event("app_mention")
def handle_mention(event, say):
    user = event["user"]
    text = event["text"]
    say(f"안녕하세요 <@{user}>님! '{text}' 라고 하셨네요.")

if __name__ == "__main__":
    SocketModeHandler(app, APP_TOKEN).start()
```

## 7단계 — 실행 & 테스트

```bash
python3 bot.py
```

터미널에 `⚡️ Bolt app is running!` 같은 메시지가 뜨면 성공이에요. 이제 슬랙 채널에서:

```
@ai-bot-test 안녕
```

쳐보면, 봇이 바로 답장할 거예요. 이게 되면 **"멘션 감지 → 코드가 반응 → 답장"** 왕복을 실제로 완성한 거고, 이게 우리 Mattermost 어댑터에서 만들 것과 완전히 똑같은 구조예요.

## 8단계 (선택) — 진짜 AI가 답하게 해보기

`say(...)` 부분을 진짜 AI 호출로 바꾸면 됨. 예를 들어 Claude API를 쓰면:

```python
import anthropic

client = anthropic.Anthropic(api_key="여기에-Claude-API-키")

@app.event("app_mention")
def handle_mention(event, say):
    text = event["text"]
    response = client.messages.create(
        model="claude-sonnet-5",
        max_tokens=500,
        messages=[{"role": "user", "content": text}]
    )
    say(response.content[0].text)
```

이렇게 되면 "슬랙 멘션 → 진짜 AI가 답변" 왕복이 완성돼요 — 이게 정확히 우리 프로젝트 MVP의 핵심(`@ai` 멘션 → 답 돌아옴)을 슬랙으로 미리 연습해본 게 됩니다.
