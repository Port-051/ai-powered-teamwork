## 앱 먼저 설치 → 그 안에서 워크스페이스 만들기 (더 간단한 순서)

### 1단계 — 앱 설치
- **`https://slack.com/downloads/windows`** 에서 설치 파일 받아 실행
- 또는 Microsoft Store에서 "Slack" 검색 → 설치

### 2단계 — 앱 실행 → 워크스페이스 만들기
1. 앱을 열면 로그인 화면이 뜸
2. **"새 워크스페이스 만들기(Create a new workspace)"** 버튼 선택 (로그인 화면 안에 이 옵션이 있어요)
3. 이메일 입력 → 메일로 온 6자리 코드 입력
4. 워크스페이스 이름 정하기 (예: `Port_051`)
5. 팀원 초대 (나중에 해도 됨)
6. 첫 채널 이름 정하기

이러면 브라우저 왔다 갔다 할 필요 없이 **앱 하나로 설치 + 계정 생성이 끝나요.**

### 3단계 — 핵심 기능 5개 만져보기

| 기능 | 뭐냐 | 어떻게 |
|---|---|---|
| 채널(Channel) | 주제별 단체 대화방 | 왼쪽 `+` → "채널 만들기" |
| DM | 1:1 개인 메시지 | 왼쪽 "Direct Messages"에서 상대 선택 |
| 멘션(@) | 특정 사람 콕 부르기 | 메시지에 `@이름` 입력 |
| 스레드(Thread) | 한 메시지에 달린 답글 묶음 | 메시지에 마우스 올리면 "스레드로 답장" |
| 봇/앱(App) | 자동응답 프로그램 | 나중에 Hermes 봇 붙일 자리 |

**꼭 해볼 것**: 채널 만들기 → `@`로 팀원 부르기 → 스레드 답글 달기.
