## 되어 있는 것 (기초는 챙김)
- `<title>`, `<meta name="description">` 있음
- `og:title` / `og:description` 있음 (카톡·슬랙 공유 시 텍스트는 뜸)
- 시맨틱 헤딩 구조 — h1(Hero) → h2(섹션) → h3(하위) 순서 잘 지킴
- `lang="ko"` 지정, 이미지가 없어서 alt 누락 이슈는 없음

## 안 되어 있는 것 (핵심 문제들)

1. **robots.txt / sitemap.xml 없음** — 둘 다 요청해보니 403 (파일 자체가 없음). 검색엔진에 "이 사이트를 크롤링해도 된다"는 신호와 페이지 목록을 아예 안 주고 있음.

2. **순수 CSR(클라이언트 렌더링) SPA** — Vite + React만 쓰고 SSR/프리렌더가 없어서, 실제 서버가 주는 HTML엔 `<div id="root"></div>`만 있고 본문 텍스트가 없음. 브라우저에서 JS가 실행돼야 콘텐츠가 채워짐.
   - Google은 JS를 실행해서 읽긴 하지만 느리고 일부만 성공.
   - 네이버·빙 같은 다른 검색엔진이나 카톡/슬랙 링크 미리보기 봇은 JS를 안 돌리는 경우가 많아서, **빈 페이지로 인식할 가능성이 큼**.

3. **canonical URL, og:image, og:url, twitter:card 없음** — SNS에 링크 공유해도 미리보기 이미지가 안 뜸.

4. **JSON-LD 구조화 데이터 없음** — 검색결과 리치 스니펫 노출 불가.

5. **도메인이 raw CloudFront 서브도메인**(`d35i71sym3m7f7.cloudfront.net`) — 브랜드 도메인이 아니라서 검색엔진 신뢰도·색인 우선순위에 불리하고, 나중에 정식 도메인으로 옮기면 지금까지 쌓인 색인을 처음부터 다시 시작해야 함.
