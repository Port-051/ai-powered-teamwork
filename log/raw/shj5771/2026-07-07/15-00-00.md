DM 창에 "이 앱으로 메시지를 보내는 기능이 꺼져 있습니다"라고 뜨는 거 보이시죠? 이건 Slack 앱 설정에서 **"메시지 탭"** 기능을 켜야 해서 그래요.

**해결 방법:**
1. Slack API 설정 페이지(api.slack.com/apps → Demo App) 들어가기
2. 왼쪽 메뉴에서 **"App Home"** 클릭
3. 아래로 스크롤 → **"Show Tabs"** 섹션에서 **"Messages Tab"** 켜기
4. 그 아래 **"Allow users to send Slash commands and messages from the messages tab"** 체크박스도 켜기

이거 켜시면 DM으로 메시지 보낼 수 있게 됩니다.
