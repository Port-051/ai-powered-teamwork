네, PyCharm으로 하는 게 훨씬 편해요. 다만 한 가지 확인할 게 있어요 — **PyCharm은 기본적으로 WSL 안의 파이썬을 못 봐요** (WSL 연결 기능은 유료판인 Professional에만 있어요). 그러니까 가장 간단한 방법은 **WSL을 아예 안 쓰고, 윈도우에 파이썬을 따로 설치해서 PyCharm에서 그걸로 진행하는 것**이에요.

## 1단계 — 윈도우용 파이썬 설치 (WSL 말고 윈도우 자체에)

1. **`https://www.python.org/downloads/`** 접속 → "Download Python" 버튼(윈도우용) 클릭해서 설치 파일 받기
2. 설치 화면에서 **"Add python.exe to PATH"** 체크박스 꼭 체크 (중요!)
3. "Install Now" 클릭해서 설치

## 2단계 — PyCharm에서 새 프로젝트 만들기

1. PyCharm 실행 → **"New Project"**
2. 위치: 원하는 폴더 (예: `C:\Users\kimye\slack-bot-practice`) — **팀 프로젝트 폴더 말고 별도 위치**로
3. Python Interpreter: 방금 설치한 윈도우 파이썬이 자동으로 잡힐 거예요 (안 잡히면 "Add Interpreter" → System Interpreter → 방금 설치한 python.exe 경로 선택)
4. **"Create"** 클릭

## 3단계 — 패키지 설치 (터미널 안 써도 됨, 클릭으로 가능)

1. 상단 메뉴 **File → Settings** (Mac은 Preferences) → **Project → Python Interpreter**
2. **"+"** 버튼 클릭 → 검색창에 `slack_bolt` 입력 → 검색되면 선택 → **"Install Package"** 클릭

(또는 PyCharm 하단의 "Terminal" 탭 눌러서 `pip install slack_bolt` 쳐도 되는데, 이건 WSL 터미널이 아니라 **윈도우 자체 터미널**이라 훨씬 간단해요.)

## 4단계 — 파일 만들고 코드 작성

1. 왼쪽 프로젝트 탐색기에서 프로젝트 폴더 우클릭 → **New → Python File** → 이름 `bot` 입력
2. 아래 코드 붙여넣기 (토큰 두 개는 실제 값으로 바꾸기):

```python
from slack_bolt import App
from slack_bolt.adapter.socket_mode import SocketModeHandler

BOT_TOKEN = "xoxb-여기에-복사한-Bot-Token"
APP_TOKEN = "xapp-여기에-복사한-App-Token"

app = App(token=BOT_TOKEN)

@app.event("app_mention")
def handle_mention(event, say):
    user = event["user"]
    text = event["text"]
    say(f"안녕하세요 <@{user}>님! '{text}' 라고 하셨네요.")

if __name__ == "__main__":
    SocketModeHandler(app, APP_TOKEN).start()
```

## 5단계 — 실행 (버튼 클릭 한 번)

- 코드 창에서 아무 곳이나 우클릭 → **"Run 'bot'"** 클릭
- 또는 화면 오른쪽 위 **초록색 재생 버튼(▶)** 클릭

하단에 "Run" 창이 뜨면서 `⚡️ Bolt app is running!` 같은 메시지가 나오면 성공이에요. 이제 슬랙 채널에서 `@ai-bot-test 안녕` 쳐보면 답장이 올 거예요.

**끌 때**: 하단 Run 창의 빨간 네모(■) 버튼 눌러서 중지하면 돼요.
