맥으로 넘어가실 때 꼭 챙기면 좋은 것들 간단히 정리해드릴게요.

**필수 유틸리티**
- **Rectangle** (무료) — 윈도우의 창 스냅(좌우 반반 배치 등) 기능이 맥엔 기본으로 약해서, 이거 하나면 윈도우 때 쓰던 창 관리 습관 그대로 씀
- **Homebrew** — 맥의 패키지 매니저, 개발 관련 도구(node, git 등) 설치할 때 사실상 필수
- **Rancher Desktop / OrbStack** — Docker 쓰신다면 (OrbStack이 훨씬 가볍고 빠름)
- **iTerm2** — 기본 터미널보다 훨씬 편함 (지금 Claude Code도 여기서 쓰게 될 거예요)

**개발 관련 (지금 하시는 작업 고려하면)**
- **Node.js** (nvm으로 버전 관리 추천) — `landing/` Vite 프로젝트 돌리려면 필요
- **VS Code** 또는 **Cursor**
- **GitHub Desktop**은 필요 없음 — 어차피 이 폴더에서 Claude Code로 git 작업 대신 처리하기로 하셨으니까요

**적응 관련 팁**
- 단축키 `Cmd`가 윈도우의 `Ctrl` 역할, `Ctrl`은 거의 안 씀 — 처음에 제일 헷갈리는 부분
- 트랙패드 제스처(세 손가락 스와이프로 창 전환 등) 켜두면 윈도우보다 오히려 편함
- 아이클라우드/타임머신 백업 설정 미리 해두기

전공/작업 특성상 더 필요한 게 있을 수도 있는데(디자인 툴, 특정 IDE 등), 지금 하시는 작업 범위(웹 프론트, Claude Code, git) 기준으로는 이 정도면 충분할 것 같아요.
