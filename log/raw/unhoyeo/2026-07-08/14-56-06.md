  - Builds the top-level argparse parser via `hermes_cli/_parser.py` (`build_top_level_parser`) and wires ~30+ subcommands (`model`, `moa`, `fallback`, `gateway`, `cron`, `config`, `setup`, `doctor`, `claw`, etc., each implemented in its own `hermes_cli/*.py` module).

- Other entry points: `hermes-agent` console script → `run_agent.py:main` (headless/batch use), `hermes-acp` → `acp_adapter/entry.py` (IDE integration for VS Code/Zed/JetBrains), `mcp_serve.py` (MCP server mode), `batch_runner.py` (parallel trajectory batch runs), `apps/desktop` (Electron chat app talking to a `tui_gateway` backend via `@hermes/shared` JSON-RPC client), `web/` dashboard (`hermes dashboard`/`hermes serve`, FastAPI backend in `hermes_cli/web_server.py`, embeds the real TUI over a PTY-backed WebSocket at `/api/pty`).
