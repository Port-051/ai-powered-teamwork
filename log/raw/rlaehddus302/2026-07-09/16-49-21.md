## "GPT 무료분"이 뭘 가리키는 건지 — 가장 유력한 해석

지난 대화에서 확인했듯 **"OpenAI API 자체의 무료 티어"는 사실상 없습니다** (분당 3건, 구형 GPT-3.5-turbo 한정). 그런데 이 강의 FAQ가 말하는 "무료분"은 그게 아니라 다른 걸 가리키는 것으로 보입니다:

**"ChatGPT 계정(무료든 유료든)에 딸려오는 사용량을, API 결제가 아니라 Codex CLI 로그인으로 그대로 갖다 쓴다"** — 바로 앞서 Hermes 소스에서 직접 확인한 그 메커니즘입니다.

- Hermes는 실제로 `~/.codex/auth.json`(OpenAI 공식 `codex` CLI가 만드는 로그인 파일)을 읽어다 쓰는 코드가 있습니다 (`_import_codex_cli_tokens()`)
- 검색으로 확인한 사실: **"Codex is included across Free, Go, Plus, Pro..."** — ChatGPT **무료 요금제**도 Codex 사용량을 일부 받습니다
- 즉 "GPT 무료분"= **ChatGPT 무료 계정에 원래 포함된 사용량**을, API 종량제 결제 없이 Codex CLI 로그인으로 그대로 Hermes가 빌려쓰는 것 → 강의 참가자가 "GPT 무료 계정으로 로그인만 하면 된다"는 뜻으로 이 표현을 썼을 가능성이 큽니다.

이게 맞다면, 지난 대화에서 확인한 **"제3자 프로그램이 웹 세션을 몰래 흉내내는 위험한 방법"이 아니라, "OpenAI 공식 도구(Codex CLI) 로그인 결과를 정상적으로 빌려쓰는 안전한 방법"**에 해당합니다.

## 다만 "충분하다"는 주장은 검증이 안 됩니다

- ChatGPT **웹 채팅** 무료 요금제 한도는 확인됨: 5시간에 약 10건 (하루로 치면 40~50건 수준)
- 하지만 **Codex CLI 전용 무료 한도가 몇 건인지는 공개된 자료를 못 찾았습니다.** Codex는 도구 호출·코드 실행이 얽혀서 "대화 1건"보다 토큰을 훨씬 많이 씁니다. 웹 채팅 기준 숫자를 그대로 대입하면 안 됩니다.
- 그래서 "GPT 무료분 정도면 충분하다"는 강의 측 주장은, **2시간 원데이 실습 데모용으로는 맞을 수 있지만, 우리 프로젝트처럼 팀 전체가 상시로 쓰는 용도엔 검증 안 된 낙관적 표현**일 가능성이 있습니다.

## 정리

이 FAQ는 십중팔구 **"Codex CLI로 ChatGPT 계정 로그인 → 그 무료 할당량 재사용"**을 말하는 것으로 보이고, 이 방식 자체는 (지난 확인대로) 안전합니다. 다만 실제 정확한 한도는 강의 자료에 안 나와 있는 이상 확실친 않으니, FAQ에 적힌 대로 **webex로 강사에게 "무료분이 정확히 뭘 의미하는지, 하루 몇 건 정도 되는지" 직접 물어보시는 게 제일 확실**하겠습니다.
