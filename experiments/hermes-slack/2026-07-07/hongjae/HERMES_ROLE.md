# Hermes가 (지금 Slack PoC 상태에서) 해주는 역할 정리

## 1. 비서 기능 (그때그때 대화로 시키는 것)

- 질문 답변, 웹 검색
- 코드 작성 / 디버깅
- 파일 읽기·쓰기, 문서 요약
- 일정/cron 작업 예약 (정기 알림 등)

## 2. 개인 학습 기능 (뒤에서 계속 쌓이는 것)

- **세션 넘어서는 기억(Persistent Memory)**: 대화하면서 나온 정보·선호·맥락을
  계속 저장해뒀다가 다음 대화에 이어서 씀
- **사용자 모델링(Honcho 기반)**: 대화를 쌓을수록 "이 사람이 어떤 사람인지"를
  점점 더 정교하게 파악해서 응답을 맞춤
- **스킬 자동 생성/개선**: 복잡한 작업을 처리하고 나면 스스로 재사용 가능한
  "스킬"을 만들어서 다음번엔 더 잘함
- **세션 검색(FTS5)**: 예전 대화 내용을 검색해서 "그때 그거 어떻게 했지"에 답함

즉 Hermes는 단순 챗봇이 아니라 **개인을 계속 학습해서 맞춰가는 개인 에이전트**다.

## 3. 지금 안 되는 것 (Hermes에 원래 없는 기능)

- **팀 공유 지능**: 한 팀원이 알아낸 걸 다른 팀원의 AI도 아는 것.
  Hermes는 개인별로 따로 기억하고 학습할 뿐, 팀원 간 지식을 엮어주지 않는다.

## 4. PLAN.md 아키텍처와 연결

```
Mattermost (비개발자 접점)
        │
우리가 만드는 코드
  ① 메신저 어댑터
  ② 팀 공유 지능 레이어   ← 3번 항목, 아직 없음. 우리가 새로 만들 부분
  ③ 개인 ↔ 팀 지식 접합
        │
Hermes                    ← 1·2번 항목, 이미 갖고 있는 부분
```

지금 이 Slack PoC는 Hermes(①②③ 없이 그냥 Hermes 단독)만 붙여본 것이라,
1·2번은 이미 확인됐고, 3번(팀 협업 인텔리전스 레이어)은 8월 재설계 대상으로
아직 손대지 않은 상태다.
