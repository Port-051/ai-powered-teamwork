# TeamBrain

**Port_051 · SW Maestro 17기 (부산)**
팀원: 여운호 · 김동연 · 신홍재 / 멘토: 김선만

비개발자 팀이 평소 쓰던 업무 메신저에서 AI를 멘션(호출)하기만 하면, 팀의 일·결정·노하우가 저절로 쌓여 **"팀 공유 지능"**이 되고, 팀원 각자에게는 자신을 학습하는 **개인 AI**가 함께 붙는 협업 도구입니다.

터미널도, git clone도, 별도 노트 정리도 필요 없습니다. 메신저에서 AI에게 말 걸듯 일하면 끝입니다.

## 왜 필요한가

- 비개발자 팀은 AI를 개인이 산발적으로 쓰다 보니, 대화·결정·노하우가 각자 브라우저에 흩어져 팀 자산으로 남지 않습니다.
- 팀원이 휴가·퇴사하면 그가 알던 맥락이 통째로 사라집니다.
- 기존 지식 관리 도구(git 기반 등)는 비개발자에게 진입 장벽이 너무 높습니다.
- 상용 메신저 + AI 조합은 데이터가 외부 회사 서버를 거쳐, 업무 기밀 관점에서 부담이 됩니다.

## 어떻게 동작하는가

1. 팀이 자체 호스팅 오픈소스 메신저(Mattermost)를 자기 서버에 설치 → 모든 데이터가 우리 서버에만 남습니다.
2. 채널/DM에서 `@ai`를 멘션하면 AI가 응답합니다.
3. 모든 대화·결정·산출물이 자동으로 기억되어 팀 공유 뇌(팀 인텔리전스)와 개인 에이전트(Hermes 기반) 양쪽에 쌓입니다.

자세한 배경, 아키텍처, 라이선스 전략, 일정은 [`PLAN.md`](./PLAN.md)를 참고하세요.

기획 단계입니다. 아직 소스 코드는 없으며, `submission/`에 SW Maestro 제출용 초안 문서들이 있습니다.
