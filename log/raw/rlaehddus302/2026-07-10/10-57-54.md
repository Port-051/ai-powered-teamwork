제가 앞서 "사용자 생성" 버튼이 있다고 안내한 게 틀렸습니다. 정정할게요 — Mattermost 시스템 콘솔에는 원래 그런 버튼이 없고, 관리자는 콘솔에서 기존 사용자 관리(비활성화, 역할 변경 등)만 할 수 있습니다. 새 계정을 이메일 없이 만들려면 다음 두 가지 방법 중 하나를 쓰셔야 해요.

## 방법 1: docker 컨테이너 안에서 CLI로 계정 생성 (가장 확실함)

로컬 docker 환경이니 컨테이너 이름만 알면 바로 됩니다.

1. 먼저 Mattermost 컨테이너 이름 확인:
```bash
docker ps
```
(mattermost 관련 이름 찾기, 보통 `mattermost` 또는 `mattermost-mattermost-1` 같은 이름)

2. 컨테이너 안에서 사용자 생성 명령 실행:
```bash
docker exec -it <컨테이너이름> mattermost user create \
  --email test2@local.test \
  --username test2 \
  --password 'Test12345!' \
  --email-verified
```

`--email-verified` 옵션을 주면 이메일 인증 절차 없이 바로 로그인 가능합니다.

## 방법 2: 회원가입을 열어두고 직접 가입

시스템 콘솔 → **인증(Authentication) → 가입(Signup)** 에서 **"이메일로 가입 허용(Enable open server)"** 을 켜두면, 로그아웃 후 로그인 화면에서 "계정 만들기"로 직접 가입할 수 있습니다. 다만 이메일 인증이 켜져 있으면 막힐 수 있으니 **"이메일 인증 필요"** 옵션도 같이 꺼두세요.

---

`docker ps` 결과를 보여주시면 정확한 컨테이너 이름으로 명령어 맞춰드릴게요.
