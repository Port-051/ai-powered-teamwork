## 2. 프로젝트 기획서 (10p 이내)

## □ 목적 및 필요성

### ㅇ 문제인식
- 비개발자 팀은 AI(ChatGPT·Claude 등)를 **개인이 각자 브라우저에서** 산발적으로 쓴다 → 대화·결정·노하우가 흩어져 **팀 자산으로 축적되지 않는다.**
- 팀원이 휴가·퇴사하면 그가 알던 맥락이 통째로 사라진다. "그 건 어떻게 됐지?"를 사람 붙잡고 물어야 한다.
- 지식관리·협업 도구(git·위키 등)는 **비개발자에게 진입장벽**이 높고, 기록·공유가 **별도의 일**이라 미뤄진다.
- 상용 메신저+AI(Slack AI 등)는 **데이터가 외부 회사 서버를 경유** → 업무 기밀 부담 + 구독 종속.
- **팀 스스로가 1차 사용자**: 우리 팀(개발 연수생 3인)이 협업 과정에서 매일 겪는 실제 문제다. `[확인필요: 팀 자체 경험 + 주변 비개발자 팀 인터뷰 N건]`

### ㅇ 기획의도
- 팀이 **평소 쓰던 메신저에서 AI에게 말 걸듯** 일하면, 기록·공유·개인화가 **자동으로** 일어나게 한다.
- 검증된 오픈소스(Hermes 학습엔진 + Mattermost 메신저)를 조합하되, **아무도 안 만든 '팀 협업 지능 레이어'를 우리가 창조**한다. (엔진 재발명 리스크 제거 → 차별 지점에 역량 집중 → 소마 기간 내 완주)

## □ 프로젝트 개요

### ㅇ 프로젝트 소개
- 팀이 자기 서버에 **Mattermost(오픈소스 메신저)를 설치** → 모든 데이터가 우리 서버에만 남음(데이터 주권).
- 팀원이 채널/DM에서 **`@ai` 멘션** → AI 응답. 모든 대화·결정이 자동 기억되어 **팀 공유 뇌 + 개인 학습 에이전트**로 축적.

### ㅇ 주요 기능
| 기능 | 설명 |
|---|---|
| 주요 기능1 — 메신저 내 AI 호출 | Mattermost에서 `@ai` 멘션으로 AI와 대화 (비개발자 무설정 사용) |
| 주요 기능2 — 팀 공유 지능 | "여운호가 알아낸 걸 김동연도 자기 AI에게 물으면 안다" (권한·비밀 보호) |
| 주요 기능3 — 개인 학습 에이전트 | 팀원 각자를 학습해 개인 최적화 (Hermes 학습 루프·사용자 모델링 활용) |

### ㅇ 시장분석
- 경쟁/유사: **Slack AI·MS Copilot·Notion AI** = 상용·외부서버·구독 종속. **자체호스팅 데이터주권·개인/팀 이중지능·비개발자 무설정**이 없음.
- 오픈소스 진영(Mattermost, Rocket.Chat)엔 봇은 있으나 **팀 협업 지능(개인·팀 학습 결합)** 제품은 부재.
- `[확인필요: 협업 SaaS 시장 규모 수치, 경쟁제품 비교표]`

### ㅇ 시스템 구성도
```
[팀원] ──@ai 멘션──▶ [Mattermost 순정·자체호스팅]   ← 데이터 주권
                            │ REST / WebSocket API
        [★우리 코드: ①Mattermost 어댑터 ②팀 협업 지능 레이어 ③개인↔팀 접합]
                            │
        [Hermes 포크 (MIT): 개인 학습·세션 넘는 기억·사용자 모델링]
```
`[다이어그램 이미지로 정식화 예정]`

### ㅇ 개발환경
| 구분 | 항목 | 세부 |
|---|---|---|
| SW | OS | Ubuntu Linux (서버), macOS/Windows (개발) |
| SW | 개발도구 | VS Code, Docker, Git/GitHub |
| SW | 개발언어 | Python (Hermes·에이전트), TypeScript (대시보드) |
| AI | 사용모델 | Claude·GPT·Gemini + 저비용 오픈모델 혼용 (OpenRouter 경유로 비용 최적화) |
| AI | 활용방식 | 메신저 멘션 → 에이전트 응답·자동 기억·개인 학습 |

### ㅇ AI 활용 전략
- AI가 **제품의 본체**: 대화 응답 + 자동 지식 축적 + 개인 학습 루프 + 팀 지식 통합.
- Hermes의 자기개선(경험→skill 생성·개선)·세션 넘는 기억·사용자 모델링을 엔진으로 활용.
- 초기엔 규칙 기반 + 범용 LLM, 데이터 축적 후 개인·팀 모델 정밀화.
