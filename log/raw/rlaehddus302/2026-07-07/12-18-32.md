## 2) 슬랙 설치 & 익숙해지기 (Windows 11 기준)

익숙해지는 게 목적이니, **무료 플랜**으로 우리 팀 워크스페이스 하나 만들어서 셋이 실제로 대화해보는 걸 추천해요. 순서대로 하면 돼요.

참고: 슬랙은 **Windows 앱**이에요. WSL(우분투)이 아니라 그냥 윈도우에 깔면 됩니다.

### 단계 1 — 워크스페이스(우리 팀 공간) 만들기
"워크스페이스"는 카톡으로 치면 "우리 팀 전용 채팅방 묶음"이라고 보면 돼요.

1. 브라우저에서 **`https://slack.com/get-started`** 접속 → **"워크스페이스 만들기(Create a workspace)"** 클릭
2. 이메일 입력 → 메일로 온 6자리 코드 입력
3. 워크스페이스 이름: 예) `Port_051` / 프로젝트명 입력
4. 팀원 이메일(여운호·신홍재)을 초대 → 나중에 초대해도 됨
5. 첫 채널 이름 정하기: 예) `#general`, `#기획`
6. 완료되면 `포트051.slack.com` 같은 우리 팀 주소가 생겨요

> 만든 사람이 관리자(오너)가 돼요. 김동연님이 만들면 초대 링크를 팀에 뿌리면 됩니다.

### 단계 2 — 데스크톱 앱 설치 (Windows)
브라우저로도 되지만, 실무 감을 잡으려면 앱이 좋아요.

- 방법 A(간단): **`https://slack.com/downloads/windows`** 에서 설치 파일 받아 실행
- 방법 B(윈도우 스토어): 시작 메뉴 → Microsoft Store → "Slack" 검색 → 설치
- 설치 후 앱 열고 → 방금 만든 워크스페이스 주소(`포트051.slack.com`)로 로그인

### 단계 3 — 핵심 기능 5개만 만져보기
익숙해지려면 이것만 해보면 충분해요. **괄호 안이 나중에 우리가 Mattermost에서 똑같이 붙일 개념**이에요:

| 기능 | 뭐냐 | 어떻게 |
|---|---|---|
| **채널(Channel)** | 주제별 단체 대화방 | 왼쪽 `+` → "채널 만들기". 공개(public)/비공개(private) 구분 있음 |
| **DM** | 1:1 개인 메시지 | 왼쪽 "Direct Messages"에서 상대 선택 |
| **멘션(@)** | 특정 사람 콕 부르기 | 메시지에 `@이름` 입력 → 그 사람에게 알림 감. **우리 제품의 `@ai 봇 부르기`가 바로 이 방식** |
| **스레드(Thread)** | 한 메시지에 달린 답글 묶음 | 메시지에 마우스 올리면 "스레드로 답장" |
| **봇/앱(App)** | 자동응답 프로그램 | 나중에 Hermes 봇을 붙일 자리. 지금은 "이런 게 있구나"만 |

**꼭 해볼 것**: 채널 하나 만들고 → `@` 로 팀원 부르고 → 아무 메시지에 스레드로 답글 달아보기. 이 세 개가 우리 제품 UX의 뼈대예요.

- 앱(봇) 연동은 무료도 되니 나중에 실습 가능.
