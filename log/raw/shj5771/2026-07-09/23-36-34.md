**1. Node.js 설치 (아직 없으면)**
- 터미널(Terminal) 앱 열기 (런치패드에서 검색하면 나와요)
- Homebrew 먼저 설치 (맥 패키지 관리자):
  ```
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  ```
- 설치 끝나면 Node.js 설치:
  ```
  brew install node
  ```

**2. Claude Code 설치**
```
npm install -g @anthropic-ai/claude-code
```

**3. 이 프로젝트 레포 받아오기**
```
git clone https://github.com/Port-051/ai-powered-teamwork.git
cd ai-powered-teamwork
```
(GitHub 계정 로그인 창이 뜨면 본인 GitHub 계정으로 로그인)

(예: `git config user.name "shj5771"` — 기존에 쓰시던 것과 똑같이)
