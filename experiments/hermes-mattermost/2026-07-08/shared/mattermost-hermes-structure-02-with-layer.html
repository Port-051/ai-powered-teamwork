팀 지능 레이어

Mattermost와 Hermes 사이(또는 여러 팀원의 Hermes 세션 사이)에서 대화를 가로채, 팀 지식으로 남길지 판별하고 구조화해서 다른 팀원 세션에도 흘려보낸다. 별도 프로세스로 동작 (Mattermost 플러그인 아님 — 라이선스 원칙).

① 프라이버시 필터 채널 타입(DM/공개) + 룰베이스·AI 판별로 "팀 지식 vs 개인 대화" 구분
② 지식 체계화 엔진 비정형 대화를 결정사항·진행상황·열린질문 같은 구조로 요약·축적
③ 개인↔팀 지식 브릿지 권한(채널 멤버십)을 상속받아, 누구의 세션에 어떤 팀 지식을 보여줄지 결정

③이 팀원별로 걸러진 지식을 각자의 세션에 주입

엔진 · 로직 (여운호)

Hermes 세션 A

여운호의 채널/DM 세션. 팀 지능 레이어가 흘려준 지식이 이 세션의 맥락에도 함께 들어옴.

공유 지식 반영됨

엔진 · 로직 (김동연)

Hermes 세션 B

김동연의 채널/DM 세션. 원래는 A의 대화를 몰랐지만, 레이어를 거쳐 같은 지식을 공유받음.

공유 지식 반영됨

각 세션이 응답이 필요한 순간
조립된 프롬프트를 API로 전달

두뇌 · 외부 서비스

LLM API
(설정한 provider — Claude 등)

실제로 "생각해서" 답을 만드는 부분. 팀 지능 레이어가 추가한 맥락이 있든 없든, 여기서 하는 일 자체는 동일 — 프롬프트를 받아 답을 생성.

답변 생성만 담당
이전 버전과 달라진 점 — Hermes 혼자였을 땐 세션이 대화방 단위로 완전히 격리됐다. 팀 지능 레이어가 그 사이에서 "이건 팀 지식으로 남길만한가"(①)를 판별하고, 구조화해서(②) 저장한 뒤, 권한 범위 안에서(③) 다른 팀원의 세션에도 주입한다 — 이 ①②③이 PLAN.md에서 말하는 "아무도 안 만든 새 부위"다.
