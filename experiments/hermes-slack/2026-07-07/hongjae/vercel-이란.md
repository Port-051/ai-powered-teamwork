# Vercel이란

## 한 줄 정의

**Next.js로 만든 프론트엔드(랜딩페이지) 코드를 push하면 대신 빌드해서 인터넷에 띄워주는 호스팅 서비스.**

서버를 직접 사서 세팅할 필요 없이 "여기 코드 있으니 인터넷에 올려줘"만 하면 되는 개념.

## 특징

- 코드를 push할 때마다 자동으로 다시 빌드·배포 (CI/CD가 내장돼 있는 느낌)
- 무료로 HTTPS 주소를 하나 준다
- Next.js 만든 회사가 Vercel이라 궁합이 제일 좋음 (다른 프레임워크도 되지만 Next.js가 제일 매끄러움)
- **서버리스 방식**: 요청이 올 때만 잠깐 켜졌다 꺼짐. "항상 켜져서 뭔가를 듣고 있어야 하는" 용도엔 안 맞음.

## 우리 프로젝트에 적용

| 용도 | 어디에 올릴지 | 이유 |
|---|---|---|
| Next.js 랜딩페이지 | **Vercel** | 사람이 요청할 때만 응답하면 되는 프론트엔드라 서버리스와 궁합이 좋음 |
| 팀 지능 레이어 (Mattermost/Slack 어댑터, `team-intelligence/`) | Vercel ❌ → Fly.io/Railway 같은 상시 서버 | Mattermost/Slack WebSocket을 항상 붙어서 듣고 있어야 하는데, Vercel은 요청 없을 때 꺼지는 방식이라 안 맞음 |

## 요약

**"Next.js 랜딩페이지 → Vercel", "팀 지능 레이어(Node.js 상시 프로세스) → Fly.io/Railway 같은 별도 호스팅"** 으로 나눠서 배포한다.
