# 팀 공유 미해결 이슈

## 기획서 docx (submission/기획서_TeamBrain_Port051.docx)
- 목차의 점선 리더(leader dots)·하이퍼링크가 원본 양식과 여전히 다름 (2026-07-03 기준 미해결).
- 목차 페이지 번호가 전부 "1"로 표시됨 — TOC 필드가 Word에서 열릴 때 실제 페이지로 계산돼야 하는데 아직 계산이 안 된 상태. Word로 열어서 필드 업데이트(F9 등)하면 해결될 가능성 높음.
- "1. 프로젝트 요약" 섹션을 제목 바로 아래로 옮긴 뒤 분량이 많아 목차가 3페이지로 밀리는 문제 — 내용 압축 작업이 완결되지 않음.
- 맥/윈도우에서 docx 렌더링이 다르게 보이는 이유에 대한 질문이 있었으나 아직 답변/조사 안 됨.
- Google Docs로 문서를 열람할 수 있게 연결해달라는 요청(맥 환경 Pages 렌더링 차이 때문) — 가능 여부 미확인.

## 참고
- 위 이슈들은 여러 팀원이 같은 파일을 동시에 손보면서 생긴 충돌/반복 수정의 결과이므로, 이어서 작업할 때는 `submission/reference/기획서_원본양식.docx`를 기준으로 다시 대조하고 시작하는 게 안전함.
