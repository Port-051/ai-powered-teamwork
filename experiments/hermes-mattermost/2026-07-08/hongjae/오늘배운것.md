# 오늘 배운 것 (2026-07-08)

## Docker / 컨테이너

- **컨테이너**: 프로그램을 필요한 모든 것(코드·라이브러리·설정)과 함께 격리된 상자에 담아 실행하는 방식. 직접 설치 안 해도 "이미 완성된 상태"를 받아서 켜기만 하면 됨.
- **Docker**: 이 상자들을 받고, 실행하고, 서로 연결해주는 도구.
- 오늘 실제로 띄운 것: `docker-compose.yml` 하나로 Postgres(DB) + Mattermost 두 컨테이너를 동시에 실행. `docker compose ps`로 상태 확인, `docker exec`로 컨테이너 내부에 들어가 명령 실행 가능.
- WSL엔 Docker Desktop(GUI) 대신 `get-docker.sh` 스크립트로 Docker Engine(CLI)만 설치 — 가볍고 별도 Windows 앱 설치가 필요 없음.
- `sudo`는 비밀번호 입력용 진짜 터미널이 있어야 동작 — Claude Code 세션 안에서는 안 되고, 사용자가 직접 여는 WSL 터미널에서 해야 함.

## Mattermost 서버 / 데이터베이스

- Mattermost는 대화(채널 메시지·DM 전부)를 Postgres DB의 `posts` 테이블에 **평문으로** 저장한다. 종단간 암호화 없음.
- 즉 **DB 접근 권한이 있는 관리자는 마음만 먹으면 DM을 포함한 모든 대화를 볼 수 있다.** 이건 Mattermost만의 특성이 아니라 자체 호스팅 메신저 대부분의 공통점.
- "데이터 주권 확보(외부 회사 서버 안 거침)"는 **외부 벤더가 못 본다는 뜻**이지, **그 팀 관리자도 못 본다는 뜻은 아님** — 나중에 마케팅 문구 쓸 때 정확히 구분해야 함.
- 채널은 `type` 컬럼으로 공개(O)/비공개(P)/DM(D) 구분됨. 지금은 공개 채널 2개(Off-Topic, Town Square)만 있음.
- `mmctl` 명령으로 서버 안에서 직접 유저 생성/비밀번호 변경/권한 부여 가능 (`--local` 플래그로 웹 가입 없이도 관리자 계정 즉시 생성 가능).
- 회원가입 화면에 "계정 만들기" 링크가 안 보일 때는 `/signup_email` 같은 직접 주소로도 안 되면 서버의 `EnableOpenServer` 설정이 꺼져 있는 것 — 이땐 `mmctl user create`로 서버 안에서 직접 만드는 게 확실함.

## ngrok (임시 공개 URL)

- 내 컴퓨터에서만 열리는 `localhost` 서버를, 인터넷 어디서나 접속 가능한 임시 주소로 바꿔주는 도구.
- 무료지만 계정 가입 + authtoken 등록이 필요해짐 (예전엔 없이도 됐다고 함).
- 무료 플랜 제약: 껐다 켤 때마다 URL이 바뀜, 연결 수 제한 있음. 팀 테스트용으론 충분.
- 컴퓨터를 끄거나 ngrok을 재시작하면 팀원에게 준 링크가 죽는다 — 계속 쓰려면 결국 Fly.io/Railway 같은 곳에 정식으로 올려야 함.

## 팀 지능 레이어 설계 관련 논의 (오늘 대화 요약)

권한 필터링(DM/비공개 채널을 팀 지식으로 안 올리는 것)은 로직만 보면 단순한 안전장치이고, 진짜 어려운 건 **①요약(추출) 품질**과 **②검색 품질**이라는 이야기를 나눴다.

- **①요약 품질**: "이 대화 요약해줘" 식이 아니라, 뽑을 항목(결정사항/진행상황/열린질문/참고링크 등)을 스키마로 고정해서 시키는 게 핵심. 잡담까지 다 요약하지 않도록 "팀 지식으로 남길 가치가 있는가"를 먼저 거르는 1차 분류가 필요. 품질 확인은 감이 아니라 하루치 대화를 사람이 직접 이상적으로 요약해보고 AI 결과와 비교하는 골든셋 평가로.
- **②검색 품질**: 소규모 팀 MVP 단계에선 검색(임베딩/벡터DB) 자체가 필요 없을 수 있음 — 요약이 아직 작을 때는 그냥 문서 전체를 매번 컨텍스트에 통째로 넣으면 됨(지금 `CLAUDE.md`를 매번 통째로 읽는 것과 같은 방식). 문서가 너무 커지면 그때 가서 진짜 검색을 얹는 순서.
- 우선순위 합의: **① 요약 품질 → ② (필요해지면) 검색 → ③ 시장 검증(팀들이 실제로 쓰고 싶어하는지)** 순으로 가보기로 함.

> 참고: 이 설계 논의를 기획 문서 쪽(`port_051/knowledge-layer-design-drafts.md`)에 초안으로 올릴지는 아직 결정 안 함 — 오늘은 일단 개인 학습 메모로만 남김.
