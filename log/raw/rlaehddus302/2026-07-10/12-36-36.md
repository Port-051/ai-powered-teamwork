### assistant


WSL이니까 `start`(systemd) 말고 `run`으로 켜시면 됩니다:

```bash
second gateway run
```

터미널 닫아도 계속 돌게 하려면 tmux에 넣어서:
```bash
tmux new -s second 'second gateway run'
```
나중에 로그 보러 들어가려면 `tmux attach -t second`.

(참고: 멀티플렉싱을 이미 끄셨다는 전제입니다 — `hermes config set gateway.multiplex_profiles false` 하셨는지 확인해두세요. 안 그러면 아까처럼 "이미 멀티플렉서가 서빙 중"이라는 에러가 날 수 있습니다.)
