## 4. 랜딩페이지: Vite/AWS → Next.js/Vercel 전환
- 배포된 랜딩페이지(당시 CloudFront, React+Vite CSR) SEO 점검 → robots.txt/sitemap 없음, 순수 CSR이라 크롤러가 빈 `<div id="root">`만 받음, canonical/og:image/JSON-LD 없음 등 구조적 한계 확인 → Next.js(SSR/SSG) 전환을 결정.
- Next.js 마이그레이션 진행: App 전체를 클라이언트 컴포넌트로 전환, Vite 전용 설정 제거 후 Next.js 설정으로 교체, robots.txt/sitemap 추가, 빌드 검증(실제 HTML에 h1·meta description이 서버 렌더링되는지 직접 확인).
- 배포 인프라에서 예상 밖 장애물: 조직(Port-051) GitHub repo가 Private + **Free 플랜**이라 fork 자체가 불가능(`allow_forking` 설정 문제가 아니라 플랜 제약) → Vercel도 "Private organization 배포는 Pro 플랜 필요"로 막힘 → 결국 **`landing/` 폴더만 subtree-split해서 여운호 개인 GitHub 계정에 별도 레포(`teambrain-landing`) 생성 후 그쪽을 Vercel에 연결**하는 방식으로 우회. 이후 조직 레포(main)와 개인 배포용 레포 두 곳에 매번 각각 반영(동기화)하는 방식으로 운영 중.
- `https://teambrain-landing.vercel.app/`으로 정상 배포 확인(HTTP 200, 메타 정상). favicon·og:image를 `next/og`로 코드 생성(브랜드 컬러 그라데이션 적용), `metadataBase`를 Vercel 자동 URL로 처리해 경고 제거.
- 멘토링 결정사항인 "운영체제 제한 없음" 문구 추가·배포 반영.
- 세로 스크롤은 스냅(snap) 방식을 제거해 일반 스크롤로 변경하되, 기능 소개 섹션(`.features`)의 가로 스크롤/슬라이드는 데스크톱에서 그대로 유지(모바일은 기존대로 세로 스택). 빌드 결과물에서 관련 CSS 완전히 제거됐는지 확인 후 커밋.
