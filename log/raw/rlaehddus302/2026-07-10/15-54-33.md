## second 프로파일 삭제 명령

```
hermes profile delete second
```

공식 문서 기준으로 이 명령 하나가 **알아서 다 정리**해줍니다:
- 게이트웨이(gateway) 프로세스 중지
- systemd/launchd 서비스 제거
- 자동 생성됐던 `second` 별칭 명령어 제거
- **그 프로파일의 모든 데이터 삭제** (`~/.hermes/profiles/second/` — 설정, `.env`의 토큰, 메모리, 상태 DB 통째로)

실행하면 확인용으로 프로파일 이름(`second`)을 직접 타이핑하라고 물어봅니다. 건너뛰려면 `--yes`를 붙이면 되는데, **되돌릴 수 없는 삭제라 그냥 확인 절차대로 이름 쳐서 지우는 걸 권장**합니다.

⚠️ 참고: `default` 프로파일은 이 명령으로 못 지웁니다(전체를 지우려면 `hermes uninstall`). 지금 지우려는 건 `second`니까 문제 없어요.

## 삭제 전에 멀티플렉싱부터 정리하는 게 안전

지금 상태가 "멀티플렉싱이 제대로 안 걸린 것" 같다고 했으니, 깨끗하게 다시 하려면 이 순서를 권합니다:

1. **멀티플렉싱 끄기**: `hermes config set gateway.multiplex_profiles false`
2. **second 삭제**: `hermes profile delete second`
3. **default 게이트웨이 재시작**: `hermes gateway restart`

이렇게 하면 default만 남은 깨끗한 상태가 되고, 거기서 멀티플렉싱을 처음부터 다시 설정하면 됩니다.

이 명령들은 되돌리기 어려운 작업(특히 삭제)이라 **직접 확인하시고 터미널에 치시는 걸** 권합니다. 프롬프트 앞에 `!`를 붙이면(`!hermes profile delete second`) 이 세션에서 바로 실행하고 결과를 같이 볼 수도 있어요.

참고로 삭제 후 멀티플렉싱을 **다시 제대로 거는 절차**도 이어서 정리해드릴까요? (아까 표에서 Distribution이 비어 있던 게 왜 그런지 포함해서)
