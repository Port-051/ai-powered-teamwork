## 답변

특정 사용자만 특정 봇을 부를 수 있게 하려면 **`{PLATFORM}_ALLOWED_USERS` 환경변수**로 게이트웨이 레벨에서 허용 목록(allowlist)을 걸면 됩니다. Mattermost는 `MATTERMOST_ALLOWED_USERS`.

```bash
# ~/.hermes/profiles/dongyeon/.env
MATTERMOST_ALLOWED_USERS=동연님의_User_ID
```

- 값은 **User ID**(26자리 문자열)여야 함 — `@username`이 아님. `아바타 → Profile`에서 확인
- 여러 명 허용하려면 콤마로 구분: `MATTERMOST_ALLOWED_USERS=id1,id2`
- 설정 후 해당 profile의 게이트웨이 재시작 필요 (`hermes gateway restart`)

## 동작 방식 (중요)

- 이건 **봇 계정 하나 = profile 하나**에 걸리는 게이트웨이 레벨 필터라서, **채널에 여러 명이 있어도 이 목록에 없는 사람이 그 봇을 멘션하면 조용히 무시**됩니다 (에러 메시지도 안 보냄 — 상대방은 그냥 응답이 안 오는 걸로 인지).
- 즉 "dongyeon 봇"을 채널에 초대해놓고 `MATTERMOST_ALLOWED_USERS=동연님_ID`만 넣어두면, 같은 채널에 홍재/원호님이 있어도 그분들이 `@hermes-dongyeon`을 멘션해도 응답 안 함. **동연님만** 반응.
- 반대로 `MATTERMOST_ALLOWED_USERS`를 아예 안 비워두면(빈 값) **아무나** 그 봇을 부를 수 있게 열립니다(open access) — 지난번 설정 가이드에서 "leave empty for open access"라고 나온 부분이 그거예요. 지금 요청하신 "특정 사용자만"을 위해서는 **반드시 값을 채워야** 합니다.

## 정리 — profile별 예시

```bash
# ~/.hermes/profiles/dongyeon/.env
MATTERMOST_TOKEN=hermes-dongyeon 봇 토큰
MATTERMOST_ALLOWED_USERS=동연님_User_ID

# ~/.hermes/profiles/hongjae/.env
MATTERMOST_TOKEN=hermes-hongjae 봇 토큰
MATTERMOST_ALLOWED_USERS=홍재님_User_ID
```

이렇게 하면 봇 3개가 다 같은 채널에 있어도 각자 자기 주인 메시지에만 반응하는 구조가 됩니다.
