### assistant


Mattermost 초대 링크로 들어갔을 때 뜨는 로그인 화면에는 보통 아래에 "계정이 없으신가요? 계정 만들기(Create an account)" 링크가 작게 있다. 그 흐름은 이렇다:

1. 로그인 화면 하단/링크 부분에서 "계정 만들기" 또는 "Create Account" 클릭
2. 이메일, 사용자명(username), 비밀번호 입력해서 새 계정 생성
3. 가입 완료되면 초대 링크가 연결해준 팀에 자동으로 들어가짐

만약 그 링크가 안 보인다면 서버 설정 때문일 수 있다:
- **가입 방법 제한**: 관리자가 System Console에서 "이메일 가입"을 꺼놨을 수 있음 (예: OAuth/SSO만 허용)
- **이메일 도메인 제한**: 특정 도메인 이메일만 가입 허용하도록 막아놨을 수 있음
- **초대 링크가 만료/잘못됨**: 링크 자체가 팀 초대가 아니라 그냥 로그인 페이지 URL이라 가입 옵션이 안 뜨는 경우

이 경우엔 서버를 관리하는 사람(팀 내 admin, 아마 본인이거나 다른 팀원)이 System Console → Authentication → Signup에서 "Enable open account creation"이 켜져 있는지 확인해야 한다. 본인이 Mattermost 서버 관리자 계정을 갖고 있다면 System Console에서 직접 확인해줄 수 있는데, 확인해볼까요?
