## 원인 추정

지난번에 `pip3 install slack_bolt`를 실행하신 로그를 보니, **PyCharm 안의 터미널이 아니라 별도 창(윈도우 cmd/파워셸)에서 실행**하신 것 같아요. 그러면 패키지가 **"컴퓨터 전체 파이썬"**에 깔리고, PyCharm이 이 프로젝트용으로 만들어둔 **`.venv`(도시락통) 안에는 안 들어가요.** PyCharm은 `.venv` 안만 들여다보니까, "slack_bolt 못 찾겠다"고 빨간 줄을 긋는 거예요.

(참고로 `안녕하세요`, `라고`, `하셨네요` 밑에 있는 노란/빨간 물결선은 그냥 **맞춤법 검사기**예요 — 한글 텍스트를 영어 사전이랑 대조하다 보니 "모르는 단어"로 표시하는 것뿐이라 **신경 안 쓰셔도 되는 것**이에요. 진짜 문제는 화면 우측 위 "오류 4개" 쪽이에요.)

## 해결 방법 — PyCharm 안에서 다시 설치하기

### 방법 A: PyCharm 내장 터미널에서 설치 (제일 확실함)

1. PyCharm 화면 **맨 아래쪽**에 있는 **"터미널(Terminal)"** 탭 클릭 (없으면 상단 메뉴 View → Tool Windows → Terminal)
2. 터미널 프롬프트 맨 앞에 **`(.venv)`** 라고 표시되는지 확인 — 이게 "지금은 이 프로젝트 전용 도시락통 안에서 작업 중"이라는 뜻이에요
3. 거기서 다시 입력:
   ```
   pip install slack_bolt
   ```
4. 설치 끝나면 코드 창의 빨간 밑줄이 사라질 거예요 (몇 초 걸릴 수 있음)

### 방법 B: 설정 화면에서 클릭으로 설치 (터미널 아예 안 씀)

1. 상단 메뉴 **File → Settings** → **Project: slack-bot-practice → Python Interpreter**
2. 이 화면에 지금 뭐가 설치돼 있는지 목록이 보여요 — `slack_bolt`가 있는지 확인
3. 없으면 **"+"** 버튼 클릭 → `slack_bolt` 검색 → 선택 → **"Install Package"**

## 확인해볼 것

설정 화면(Settings → Python Interpreter) 맨 위에 표시되는 **인터프리터 경로**가 `...\slack-bot-practice\.venv\Scripts\python.exe` 처럼 **`.venv` 폴더 안의 파이썬**을 가리키고 있는지 확인해보세요. 만약 그냥 `C:\Python3xx\python.exe` 같은 걸 가리키고 있으면, 인터프리터 자체가 venv로 안 잡혀있는 거라 그것부터 venv로 바꿔야 해요.

이 두 가지(방법 A 또는 B) 중 하나로 다시 설치해보시고, 그래도 빨간 줄이 안 사라지면 화면 다시 캡처해서 보여주세요.
