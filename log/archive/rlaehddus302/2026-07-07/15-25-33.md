## Hermes Agent가 뭘 하는 물건인가

한 줄로: **"대화할 때마다 리셋되는 챗봇"이 아니라, 쓸수록 기억이 쌓이고 스스로 노하우(스킬)를 만들어 똑똑해지는 자율 에이전트.** IDE에 붙는 코딩 코파일럿도 아니고, 특정 API를 감싼 챗봇 래퍼도 아니라고 스스로 규정함. 개인 PC에서도, 클라우드에서도 돌아가고, 사람이 계속 붙어있지 않아도 알아서 동작하도록 설계됨.

### 핵심 구조 — "닫힌 학습 루프(closed learning loop)"

- **에이전트가 알아서 정리하는 기억**: 대화 중 중요한 걸 스스로 기억으로 저장하고, 주기적으로 "이거 기억해둘까?" 하고 스스로 되짚어봄(periodic knowledge nudges).
- **세션을 넘나드는 검색**: FTS5(전문 검색 엔진)로 과거 대화를 검색하고, LLM이 그걸 요약해서 다시 맥락에 넣어줌.
- **사용자 모델링**: Honcho라는 방식(대화형으로 사용자상을 추론하는 기법)으로 "이 사람이 어떤 사람인지"에 대한 프로필을 대화가 쌓일수록 정교하게 만들어감.
- **스킬(절차 기억)**: 어려운 문제를 한 번 풀면, 다음에 또 쓸 수 있도록 "이렇게 풀면 된다"는 문서(스킬)를 스스로 만들어 저장. agentskills.io라는 공개 표준을 따라서, 다른 사람 스킬도 가져다 쓸 수 있고 내 스킬도 공유 가능.

### 기억(memory) 저장 구조 — 우리 프로젝트에서 제일 중요한 부분

- **기본 내장 기억**: `MEMORY.md`, `USER.md` 같은 파일 형태로 항상 켜져 있음(끌 수 없음).
- **외부 메모리 provider**: Honcho, Mem0, Hindsight 등 다양한 외부 기억 저장소 중 하나를 골라 붙일 수 있음. 단, **한 번에 하나만** 활성화 가능.
- CLI로 `hermes memory setup`(연결), `status`(현재 뭐 붙어있는지 확인), `off`(외부 provider 끄기, 내장 기억은 유지) 가능.
- `hermes sessions`로 대화 세션 단위 관리(목록·검색·내보내기(JSONL)·삭제·보관 등) — 즉 "대화 기록"과 "기억"이 분리된 개념으로 관리됨.

### 연결(gateway) — 우리가 Mattermost로 바꿔치기할 부분

- `hermes gateway`가 메신저 연동을 전담. Slack뿐 아니라 Telegram·Discord·WhatsApp·Signal·Matrix·Teams 등 20개 이상 플랫폼을 "게이트웨이"라는 통일된 구조로 연결.
- `run`(포그라운드 실행), `start/stop/restart`(백그라운드 서비스), `status`, `setup`(대화형 설정) 같은 명령으로 관리.
- **여기가 핵심**: PLAN.md 아키텍처에서 우리가 만드는 "Mattermost 어댑터"는, 이 gateway가 Slack에 붙는 것과 똑같은 자리에 Mattermost를 붙이는 작업이라고 보면 됨.

### 우리 프로젝트와 무관해서 몰라도 되는 기능

- 6가지 실행 백엔드(Docker/SSH/Daytona/Singularity/Modal 등 분산 실행), MCP 서버 연동, 웹 검색/브라우징/이미지 생성 도구, 크론 자동화, 서브에이전트 병렬 실행, 강화학습 훈련(Atropos) — 이런 건 Hermes의 "개인 비서로서의 완성도"를 위한 부가 기능이고, 우리가 가져다 쓸 건 **기억 시스템**뿐이라 지금 단계에선 몰라도 됨.

### 정리 — 우리 프로젝트 관점에서 알아둘 3가지

1. Hermes의 진짜 핵심은 "대화 → 자동 기억 → 다음 세션에 재활용"이 되는 **기억 파이프라인**이고, 이게 PLAN.md에서 말하는 "개인 학습 에이전트" 역할 그 자체.
2. 기억이 `MEMORY.md`/`USER.md` 같은 **파일 형태**로 남는다는 게 핵심 포인트 — 나중에 "팀 공유 지능 레이어"가 이 개인 기억 파일들을 어떻게 들여다보고 엮을지가 설계 과제가 됨.
3. gateway 구조는 이미 "메신저 하나 붙이는 인터페이스"로 일반화돼 있어서, Mattermost 어댑터를 만들 때 이 구조를 참고하면 뭘 구현해야 할지 감이 잡힘(멘션 이벤트 받기 → Hermes에 전달 → 응답 받아서 되돌려주기).
