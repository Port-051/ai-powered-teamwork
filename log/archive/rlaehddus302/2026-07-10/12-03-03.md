### assistant


세 가지 방법이 있는데, 상황에 따라 골라 쓰면 됩니다.

**1. profile 이름이 곧 명령어 별칭 (제일 간단)**

`hermes profile create <name>` 할 때 자동으로 `<name>`이라는 명령어가 만들어져 있어서, 그냥 그 이름으로 치면 됩니다:
```bash
dongyeon setup           # dongyeon profile 설정
dongyeon config set model.default anthropic/claude-sonnet-4
dongyeon gateway restart
```

**2. `-p` 플래그로 한 번만 지정**

기존 `hermes` 명령어 앞뒤 아무데나 `-p <name>` 붙이면 그 명령만 그 profile로 실행됨:
```bash
hermes -p dongyeon setup
hermes -p dongyeon config edit
hermes gateway restart -p dongyeon
```

**3. `hermes profile use <name>` — sticky default (계속 그 profile로 고정)**

```bash
hermes profile use dongyeon
hermes chat              # 이제부터 -p 안 붙여도 dongyeon으로 감
hermes profile use default    # 다시 default로 복귀
```
`kubectl config use-context`처럼 "현재 작업 대상"을 바꿔놓는 방식이라, 여러 profile을 계속 왔다갔다 만지작거릴 땐 매번 `-p` 치는 것보다 편합니다.

지금 dongyeon/unho/hongjae profile 설정을 이어서 하실 거면 1번(별칭 명령어)이 제일 손에 익을 거예요.
