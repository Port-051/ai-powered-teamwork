### assistant


계정 생성 화면(설치 초기 화면, Setup Assistant)에서는 아직 한글 입력기가 안 깔려 있어서 그런 경우가 많아요. 이렇게 해보세요.

**1. 화면 우측 상단(또는 상단바)에 입력기 아이콘이 있는지 확인**
- 지구본 모양이나 국기 아이콘이 보이면 클릭해서 한국어(2벌식) 선택 가능한지 확인

**2. 없으면 "뒤로 가기"로 언어/지역 설정 단계로 돌아가기**
- 맨 처음 "언어를 선택하세요" 화면에서 한국어를 골랐는지 확인 (영어로 진행 중이면 키보드도 영어만 잡혀 있을 수 있음)
- 거기서 국가/지역을 "대한민국"으로 설정하면 보통 한글 입력기가 같이 활성화돼요

**3. 그래도 안 되면 일단 영어로 진행**
- 계정 이름(Full Name, Account Name)은 어차피 영문 권장이라(시스템 내부적으로 폴더명 등에 쓰여서), 이 단계는 영어로 입력하고 넘어가세요
- 표시 이름(예: 로그인 화면에 뜨는 이름)은 설치 끝난 뒤 `설정 → 사용자와 그룹`에서 한글로 바꿀 수 있어요
- 한글 입력기는 설치 완료 후 `설정 → 키보드 → 입력 소스`에서 추가하면 이후엔 문제없이 됩니다

지금 어느 화면에서 막히신 거예요? (예: 언어 선택 / Apple ID 로그인 / 계정 이름 입력) 알려주시면 더 정확히 짚어드릴게요.
