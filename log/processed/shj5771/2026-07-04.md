## Claude Code 사용법 학습 (Q&A 위주)
- VS Code에서 pdf/docx가 깨져 보이는 문제로 뷰어 확장 설치 논의 (pdf는 안 깨지고 docx만 문제, pdf viewer 확장은 로딩이 느리다는 단점 확인).
- "일반 Claude(메인 대화)"와 "에이전트(서브에이전트)"의 차이를 서브에이전트에 물어 확인: 메인은 대화 기억을 계속 유지하고, 에이전트는 기본적으로 대화 맥락 없이 새로 시작해 결과만 메인에 보고함(예외: fork). 이 프로젝트엔 아직 `.claude/agents/*.md` 전용 에이전트가 정의돼 있지 않음.
- `claude` 명령과 `claude agents` 명령의 차이도 확인: `claude`는 새 대화형 세션을 시작하고, `claude agents`는 이미 떠 있거나 지나간 백그라운드 세션을 관리하는 서브커맨드("Manage background agents"). 헷갈리기 쉬운 인접 개념(Claude Agent SDK, `/agents` 슬래시 커맨드, Agent 도구)도 구분해서 안내받음.
- Hermes(개인용 학습 엔진)에 대한 설명 요청 — Hermes는 팀 단위가 아니라 개인 단위 학습 도구가 맞다고 확인.
- 프로젝트의 3중 아키텍처(Mattermost 어댑터 / 팀 공유 인텔리전스 레이어 / 개인·팀 지식 브릿지) 중 "우리가 직접 짜는 부분"이 무엇인지, 어떤 식으로 설계하면 좋을지 논의 진행 — 구체적 설계안까지는 이 로그에 남아있지 않음(빈 assistant 응답 다수).
- SW Maestro 우수 프로젝트 선정 가능성, 기술적 어필 포인트에 대한 질문도 있었음 — 답변 내용은 로그에 비어 있어 남지 않음.
