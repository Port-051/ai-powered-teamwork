## Nous Portal 무료 티어의 실제 내용

| 항목 | 내용 |
|---|---|
| **월 크레딧** | **$0.10** (10센트) — "테스트해보라"는 수준이지 실사용량이 아님 |
| **가입 직후** | 10일간 `Step 3.5 Flash` 모델 임시 무료 이용 가능 |
| **10일 이후 상시 무료 모델** | `Neatron`, `Trinity` — **레이트리밋(rate limit)이 걸려 있음** |
| **Tool Gateway(웹검색·이미지생성·TTS·브라우저자동화)** | **무료 티어엔 아예 포함 안 됨** — 유료 전용 |
| **정확한 요청 횟수(분당/일당) 공식 수치** | **공개돼 있지 않음** — "rate limit이 있다"고만 문서에 언급되고 Gemini처럼 "분당 N건, 일 N건" 같은 구체적 숫자를 찾지 못함 |

## Gemini 무료 티어와의 결정적 차이

| | Gemini API 무료 티어 | Nous Portal 무료 티어 |
|---|---|---|
| 제한 방식 | **숫자로 명시** (분당 10건, 일 1,500건) | **"rate limit 있음"이라고만 함**, 정확한 수치 비공개 |
| 무료로 주는 모델 | Gemini 2.5/3 Flash (구글 자체 상용 모델) | Neatron/Trinity (Claude·GPT·Gemini가 아닌 제3의 모델, 상대적으로 덜 알려짐) |
| 예측 가능성 | 높음 — 설계에 반영 가능 | 낮음 — "테스트용"이라고 스스로 명시, 지속 사용 비권장 |
| 부가기능(검색·이미지 등) | 해당사항 없음(API라 순수 텍스트) | 무료 티어엔 아예 미제공 |

## 결론

**Nous Portal 무료 티어는 제한이 없는 게 아니라, 오히려 Gemini보다 더 제한적이고 덜 투명합니다.** 지난번 제 판단(Gemini API 무료 티어가 더 현실적)이 이번 조사로 더 확실해졌습니다 — Nous 자체 문서가 "이건 실사용이 아니라 평가용"이라고 스스로 밝히고 있고($0.10/월, 명확한 레이트리밋 수치 비공개), 무료로 주는 모델도 우리가 원하는 급(Claude/GPT/Gemini)이 아니라 상대적으로 덜 알려진 모델입니다.
