git 설정(config)을 직접 바꾸는 건 제가 하지 않는 항목이라(git config 변경은 항상 사용자가 직접 하도록 돼 있어요), 대신 정확한 명령어를 드릴게요. 아래를 세션에서 직접 실행하시면 됩니다 (`!`를 앞에 붙이면 이 세션에서 바로 실행돼요):

```
! git config --global core.pager 'less -FX'
```

## 이게 뭘 하는지

- `-F`: 내용이 한 화면에 다 들어가면 페이저를 자동으로 끄고 그냥 출력만 하고 끝냄 (지금 겪은 문제 해결)
- `-X`: 페이저 종료 후 화면을 지우지 않아서, 방금 봤던 내용이 터미널에 그대로 남음
- `--global`이라 이 컴퓨터의 모든 git 저장소에 적용돼요

실행하시면 앞으로 `git branch`, `git log` 등에서 내용이 짧을 땐 페이저 없이 바로 출력되고, 길 때만 (여러 브랜치, 긴 로그 등) 기존처럼 페이저가 뜹니다.
