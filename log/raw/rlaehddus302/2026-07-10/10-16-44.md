### assistant
Mattermost의 User ID는 **`@username`(로그인 아이디)이 아닙니다.** Mattermost 내부에서 계정마다 자동으로 부여하는 **26자리 영숫자 문자열**이에요 (예: `3uo8dkh1p7g1mfk49ear5fzs5c`).

## 확인 방법

**방법 1 — UI에서**
1. 좌측 상단 **아바타(프로필 사진)** 클릭 → **Profile**
2. 프로필 창에 표시된 **User ID** 클릭 → 자동 복사됨

**방법 2 — API로 (토큰이 있다면)**
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  https://당신의-mattermost-주소/api/v4/users/me | jq .id
```

## 왜 username이 아니라 User ID를 쓰는지

Hermes가 메시지를 받을 때 Mattermost 서버가 넘겨주는 발신자 식별 값이 `username` 문자열이 아니라 내부 고유 ID이기 때문이에요. username은 나중에 바뀔 수 있지만(사람이 개명하듯), User ID는 계정이 삭제되지 않는 한 고정이라 필터링 기준으로 더 안전합니다.

팀원 각자 이 방법으로 자기 User ID를 확인해서 알려주면, 그 값을 각 profile의 `MATTERMOST_ALLOWED_USERS`에 넣으면 됩니다. 여러 명이면 콤마로 구분:
```bash
MATTERMOST_ALLOWED_USERS=3uo8dkh1p7g1mfk49ear5fzs5c,8fk2jd9s0a7bncm1xqw4tp6r3e
```
