### user
hermes 설정할 때 무슨 앱에 연결할 지만 다시 설정하는 거 없나?

### assistant






`hermes gateway setup` (또는 `hermes setup gateway`) — 이게 딱 "어떤 메신저 앱에 연결할지"만 다시 잡는 거예요.

```bash
hermes gateway setup
```

- 모델/API 키, 터미널 설정 등은 안 건드리고 메신저 플랫폼(Slack, Mattermost, Telegram, Discord 등) 연결만 대화형으로 다시 설정합니다.
- 설정 끝나면 `hermes gateway restart`(또는 `hermes gateway run`)로 재시작해야 반영됩니다.
- profile 지정해서 하려면 `hermes -p <profile명> gateway setup`.

`hermes setup gateway`도 같은 걸 가리키는 다른 표기법이고 동일하게 동작합니다.
