**"로컬 AI 구동용"이 뭐냐면:**

지금까지 얘기한 Hermes 구조는 "우리 코드가 Claude 같은 외부 API를 호출해서 AI 기능을 쓰는" 방식이었어요. 근데 "로컬 AI 구동"은 그거랑 달라요 — **모델(LLM) 자체를 인터넷 API 호출 없이, 그 맥미니 안에서 직접 돌리는 것**을 말해요. 예를 들어 Ollama나 LM Studio 같은 프로그램으로 Llama, Qwen, Mistral 같은 오픈소스 모델을 다운받아서 그 기기의 GPU/메모리로 직접 추론(질문에 답 생성)하는 거예요. 장점은 API 비용이 안 들고 데이터가 외부로 안 나간다는 것.

**이게 스펙 결정에 왜 중요하냐면:**

Apple Silicon은 "통합 메모리(unified memory)" 구조라, CPU/GPU/메모리를 다 같이 씁니다. 로컬 AI를 돌릴 때 **얼마나 큰 모델을 돌릴 수 있느냐는 거의 전적으로 RAM 용량에 달려있어요**:
- 24GB → 대략 8B~13B급 모델(양자화 기준)까지 무난
- 48GB → 30B급 모델까지 여유
- 그 이상(64GB+) → 70B급까지 노려볼 수 있음

그리고 M4 Pro는 M4 기본형보다 GPU 코어 수와 메모리 대역폭이 더 높아서, 같은 모델을 돌려도 **토큰 생성 속도(체감 반응 속도)가 훨씬 빠릅니다.** 그러니까 로컬 AI를 진지하게 고려한다면 RAM뿐 아니라 칩 등급도 같이 영향을 받아요.

**질문 드릴게요:** 이걸 "혹시 몰라 옵션으로 열어두는" 정도로 생각하시는 건가요, 아니면 다음 프로젝트에서 실제로 로컬 모델 돌리는 걸 구체적으로 계획하고 계신가요? 후자라면 RAM을 48GB로, 어쩌면 M4 Pro까지 올리는 쪽으로 다시 계산해드릴게요 — 그럼 예산이 300~400만원을 확실히 넘어갈 가능성이 큽니다.
